# 実在校の過去の記録（史実）

ゲームの記録とは混ぜない。ゲーム開始前の実際の出来事だけを、出典付きで置く。出典は `sources.csv`。

## 甲子園の記録（ゲーム開始前）

| ファイル | 1行 | 使い道 |
|---|---|---|
| `koshien_appearances.csv` | 1校の1回の出場 | 元の記録（年・試合の勝敗・成績・出典） |
| `koshien_records.csv` | 1校×1種別の通算 | 画面が読む。出場ごとの行がある学校は `koshien_appearances.csv` から数えた値と一致する。通算だけの登録も可 |

- 範囲：夏は第107回（2025年）まで、春（選抜）は第98回（2026年）まで。ゲームは2026年4月に始まり、2026年の選抜は実際の大会なのでここに含む。ゲーム内の記録は夏は第108回、春は第99回から
- 今の学校マスター（`data/master/schools.csv`）にある学校だけ。前身校・統合前の校名での出場は、高野連の「〇回目」の数え方に合わせて今の学校に含め、`notes` に書く
- 大会が中止で試合のない出場（1918年の夏、2020年の選抜）は、出場回数に数え、勝敗には数えない。2020年の交流試合は勝敗に数えない
- `results` は試合ごとの勝敗（W 勝ち、L 負け、D 引き分け）、`result` はその大会の成績（優勝／準優勝／ベスト4／ベスト8／3回戦／2回戦／1回戦。負けた回戦）
- 出場ごとの記録がない学校は、`koshien_records.csv` に通算だけを置いてよい（`koshien_appearances.csv` に行がない）。その場合は出典の値をそのまま使い、`best_result` に「初戦敗退」（何回戦か不明）を使ってよい。準優勝の回数が分からないときは `runner_ups` を空欄にする。`appearance_years` も空欄でよい
- 検証：`python -m historical_results.koshien`

#### 出典と監査の範囲

- 通算の根拠は `sources.csv` の HS0012～HS0025（7道県×春夏のWikipedia学校別成績表）。入力の二次資料URLには「岩手勢」等の表記があるため、実際に確認した「岩手県勢」等のページURLで登録した。
- HS0026（2025夏）・HS0027（2026春）・HS0028（2025春）は高野連の出場校資料。直近の出場回数・出場年の補足に限り、過去の全勝敗の検証済み出典とは扱わない。通算行の `source_id` は学校別成績表を指す。
- HS0029は2020年選抜の出場校確認、HS0030～HS0033は能代松陽・釜石・仙台商・留萌の野球記録の継承確認に使用した。学校IDの照合資料は下表の公式資料も参照する。追加出典22件はすべて `unverified`。学校同一性の確認と、通算値の公式全試合による独立検算は区別する。
- 白樺学園・札幌日大・青森山田・花巻東・仙台育英・横手・鶴岡東の夏は、入力で2026年分を除外済みの値を維持した。現在の県勢表には対象外の2026夏が含まれるため、その表の最新通算を丸ごと採用していない。除外補正の全試合単位の独立検算は残る。
- 聖光学院の春は、県勢表の通算7回・7勝7敗を入力どおり保持した。同表の最終出場2022年は未更新で、入力の2025年はHS0028で確認した。勝敗7勝7敗を公式試合記録から再集計したわけではない。東北学院の2021夏の辞退・不戦敗の数え方も、入力の1勝1敗を保持して監査課題とする。

中止大会の取り決めは変更していない。一関第一の夏（旧一関中、1918年）、仙台育英・鶴岡東・磐城の春（2020年）は出場回数に含み、中止大会の勝敗や2020年交流試合の勝敗を加えない。鶴岡東の春2回・1勝1敗、磐城の春3回・0勝2敗はこの扱いに合うため、入力の「2020年の扱い未確定」メモは取り込み時にこの規則へ照合した。

ただし帯広農・白樺学園の春は、[高野連の2020年出場校一覧（HS0029）](https://www.jhbf.or.jp/senbatsu/outing/91-95.html)に両校がある一方、入力は0回になっている。今回は0回除外の規則に従って未登録とし、値を補わない。この欠落は中止大会を数えないという方針変更ではなく、入力修正・出典再確認が必要な課題である。

名称一致候補の学校もマスターの道県・正式名を確認した。旧校名がある通算は、その旧名と当該春夏区分の継承範囲を `notes` に記した。特に次の統合は、学校沿革と野球記録の数え方を別々に確認した。

- 能代松陽： [学校公式沿革](https://noshiroshoyo-h.com/schoolhistory/)で能代北・能代商の統合を確認。HS0030の秋田県高野連資料が2022夏を11年ぶり4度目と数えるため、能代商の夏3回を含めた4回を採用。春は2023年の能代松陽自身の1回のみ。
- 釜石： [学校公式概要](https://kas-hs.note.jp/n/n3c100526ddf9)で釜石南・釜石北の統合を確認。HS0031が2016春を釜石南時代の1996年以来2度目と数えるため、この2回を採用。
- 留萌： HS0033の学校公式野球部紹介が統合前の1971夏を挙げ、二度目の甲子園を目指すと説明するため、旧留萌の夏1回を含めた。留萌千望の記録を新たに足していない。
- 白石： [学校公式沿革](https://hakko.myswan.ed.jp/enkaku)で白石女子との統合と旧白石の1953年甲子園出場を確認。県勢表の現校名の通算も夏1回のため、その1回を含めた。
