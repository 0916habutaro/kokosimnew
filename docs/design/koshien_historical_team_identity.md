# 甲子園史実：当時の出場チームIDと学校継承通算の分離（NAT-G003）

## 目的

現行の`koshien_appearances.csv`は`(kind,year,school_id)`が一意である。1947年春の慶應普通部・慶應商工のように、**同じ大会に当時は別の2チームが実出場し、一部だけ現在の同じ学校の継承通算に含まれる**ケースを安全に記録できない。また、旧大分二1出場が大分商・大分工の両現校の歴史に現れる場合に全国の実出場数を2回と数えてしまうリスクがある。

本設計は当時の**学校・硬式野球部系列（歴史校ID）**、**実出場の正本（1チーム1大会1出場ID）**、**現校がそれを継承通算に含めるか（複数校への多対多リンク）**を別々に管理する。実際の甲子園試合は史実であり、2026年4月開始の架空ゲーム試合とは混ぜない。

## データ構造

### `historical_data/koshien_historical_schools.csv`

| 列 | 意味 |
|---|---|
| `historical_school_id` | 大会をまたいでも変わらない歴史上の学校・硬式野球部系列の永続ID（例：`HSC000001`）。現役学校の`SCH...`とは独立 |
| `historical_name` | 史料で確認できる当該系列の代表名称。当時の各大会の校名は出場表に別途残す |
| `source_id` | 当該系列が独立した学校・野球部であることの資料 |
| `notes` | 校名変更・分離・統合の経緯と、識別できる範囲。推測で継承を確定しない |

同一系列の校名変更は一つの歴史校IDを継続できる。一方、**別々に活動していた学校・野球部を、のちに同じ現役校へ統合されたことだけを理由に同一IDへまとめない**。神港系列と北神商系列、1947年当時の慶應普通部と慶應商工は別IDとする。統合後の新しい野球部系列を登録する場合は、その成立と継承範囲を別途根拠付ける。正式な学校の法的な存続・改称と野球部の競技記録の継承は同一ではない。この表のIDは史実の識別用で、現役校をゲームに追加するものではない。

### `historical_data/koshien_historical_teams.csv`

| 列 | 意味 |
|---|---|
| `appearance_id` | 永続・一意の実出場チーム識別子（大会単位）。現校IDとは別 |
| `historical_school_id` | `koshien_historical_schools.csv`への外部キー。同じ系列の年度別出場に同一IDを用いる |
| `kind,year,edition` | 夏・春、大会年、大会回次。1918年夏・2020年春の選出中止も識別可能 |
| `team_name` | 当時の公式出場校名。後年の校名で上書きしない |
| `representative_region` | 当時の公式代表地区・都県名をそのまま保持。歴史上の地域も扱うため現在の都道府県コードを強制しない |
| `source_id` | 日本高野連の大会出場一覧などの根拠 |

### `historical_data/koshien_team_attributions.csv`

| 列 | 意味 |
|---|---|
| `appearance_id` | 当時の実出場へ外部キー |
| `school_id` | 現在の学校マスターの対応ID（確認できた場合に限り登録） |
| `counts_in_school_total` | `1`：継承通算に含む、`0`：除外、`unknown`：未判定 |
| `source_id` | 公式の野球部史・掲載通算など、継承判断の根拠 |

同じ`appearance_id`が複数の現校通算へ算入されても、**全国の実出場数は実出場チーム表の行数で数える**。歴史校IDと実出場IDを一対一に固定せず、改称前後の複数大会出場を同一の歴史校IDへ結び付ける。出場行は必ず登録済みの歴史校IDを参照し、根拠のない旧校は推測で既知系列に結び付けず調査保留とする。同一の`appearance_id`と`school_id`の組合せは重複禁止。現校マスターに対応IDがない歴史校は実出場チームのみを登録でき、架空ゲームの現役参加校へ混入させない。

## 登録済みの事例と未登録の設計例

- **1947年選抜（PR #348で登録済み）**：慶應普通部・慶應商工は別々の`historical_school_id`を持ち、同じ年・同じ大会で2個の`appearance_id`を付与する。現校の慶応`SCH003225`への帰属は普通部`1`、商工`0`。全国の実出場は2件、現校の春通算は1件。商工の独立した史実を消去しない。
- **神港と北神商（17実出場を登録済み）**：旧神港（第一神港商・市神港）と旧兵庫商（北神商）は別の`historical_school_id`を持つ。現神港橘への継承が資料で確認できても両系列は統合せず、年別出場IDだけを現校通算に関連付ける。
- **1948年夏の大分二**：大会実出場は1個の`appearance_id`。大分商・大分工それぞれの歴史通算との関係は確定したものだけリンクする。`unknown`を`1`や`0`と推測しない。
- **瑞陵と愛知商**：学校・野球部の公式部史により同じ出場の継承が複数認められた場合、同じ実出場IDを複数の学校へ`1`で関連付けることも可能。その場合も全国の実出場数は1件。

## 基盤PR #347の実装範囲と旧データの境界

基盤PR #347では3つのCSVを**ヘッダーのみ**で追加した。その後PR #348で1947年春の慶応普通部・商工2出場を、後続PRで旧神港・北神商の計17出場を段階的に登録した。既存`historical_results/koshien.py`のread-only検証に、ヘッダー・必須項目・年/回次の範囲、歴史校IDの外部キーと重複、既存出典ID・現校IDの参照、重複リンク・不正値の拒否を追加する。テストの学校・試合はすべて架空にする。

旧`koshien_appearances.csv`（年度別546行）・`koshien_records.csv`（学校別通算）・`aggregate()`には新表の行を**自動で足さない**。2形式の同じ実出場を無条件に合計せず、移行後の全国集計では`appearance_id`で一意に数える。今回の`summarize_historical_attributions`は新表に載る実出場と学校帰属の**件数だけを別々に確認する補助関数**で、勝敗の集計や既存通算を書き換えない。

試合別勝敗、1918/2020中止、認定不戦勝（既設の`koshien_special_results.csv`）は別の史実属性・テーブルへ保持する。裁定の有無から実施試合を推定しない。

## 次の工程

1947年春の慶応普通部・商工2実出場、旧神港系列15・北神商系列2の計17実出場は、それぞれ歴史校ID・当時出場ID・現校継承判定を登録済み。旧学校別通算は更新していない。1948年夏の大分二は`HSC000005`／`KHA000020`の単一出場とし、大分商・大分工の両校に`counts_in_school_total=1`で共有継承済み（大分商の全15大会・27実施試合も確認）。瑞陵の1949年夏・1950年春夏の3出場は統合期の歴史校`HSC000006`／出場`KHA000021`～`KHA000023`に登録し、愛知商への共有帰属を二次資料HS0365付きで保存した。愛知商の春10回10勝9敗1分・夏8回7勝8敗は全35実施試合の主催社アーカイブと高野連出場校を照合し登録済み。統合前14出場はHSC000007・1951年再独立後1出場はHSC000008として歴史校IDを分け、統合期瑞陵3出場の既存IDを保全。1935年春の引き分けスコア差と野球部史の一次継承規則は調査を継続し、旧年度別記録との二重計上を防ぐ。各校の現在の通算表示と、全国の実出場チーム数は最後まで別の指標とする。全試合の一次資料による独立勝敗検算はNAT-G001へ保留。
