# Stage 13D-3 ローカル実機表示チェックリスト

## 起動

例:

```
python -m phase2_engine.browse_gui \
  --db out/kokosim_browse.sqlite3 \
  --data-dir data
```

前提:

SQLiteがschema v3で、player_masterとability GameStatsを含んでいること。

## 1. 起動

- ウィンドウが起動する
- 既存4タブが残っている
- 「選手・ロスター」タブがある
- 「個人成績ランキング」タブがある
- 既存の日付・大会・学校画面が崩れていない

## 2. 学校 → ロスター

- 学校戦績で学校を選択
- 「選択校のロスター・個人成績」を押す
- 選手・ロスタータブへ遷移
- 学校ロスターsub-tabが選択される
- 20人が背番号順で表示される
- 未出場bench playerも消えない
- 投手には投球成績が表示される
- 打者には打撃成績が表示される

## 3. ロスター → 選手詳細

- ロスター行をダブルクリック
- 選手検索・詳細sub-tabへ遷移
- 選手名・学校・学年・守備位置・背番号・投打が表示される
- 打撃成績が表示される
- 投手なら投手成績も表示される
- 未出場選手は「出場記録なし」になる

## 4. 選手検索

- 選手名で検索できる
- player_idで検索できる
- school_idで絞り込める
- 守備位置で絞り込める
- 検索結果選択で詳細が表示される

## 5. 大会 → ランキング

- 大会結果で大会を選択
- 「この大会の個人成績ランキング」を押す
- ランキングタブへ遷移
- 対象大会が引き継がれる
- 打撃ランキングが表示される
- 投手ランキングが表示される

## 6. metric変更

打撃:

- OPS
- 打率
- 出塁率
- 長打率
- 安打
- 本塁打
- 打点
- 得点
- 四球
- 盗塁

投手:

- 防御率
- WHIP
- 奪三振
- K/9
- BB/9
- K/BB
- K-BB%

各選択で並び順・値が更新されること。

## 7. ランキング → 選手

- 打撃rankingをダブルクリック
- 選手詳細へ移動する
- 投手rankingをダブルクリック
- 選手詳細へ移動する

## 8. 表示崩れ

- 1400x900で主要列が読める
- 1120x720まで縮小可能
- 横スクロール・縦スクロールが機能する
- 長い学校名でも操作不能にならない

## 9. read-only

GUI操作だけでSQLiteのデータ件数が変化しないこと。

## 判定

Stage 13D-3の実機確認は上記をすべてPASSした時点で完了とする。

表示上の改善事項は正式GUIではなく、まずStage 13D-3/13D-4のread model・画面契約へフィードバックする。
