# Stage 43G-67：長期保存した完全A方式の試合・個人成績読み取りと保存容量の監査

作成日：2026-10-12

## 目的

Stage43G-66では「選手1名の年度別保存ロスターは最大3年間だけを見る」という検索を実装した。一方、長期保存を考慮すると試合結果・イニング別得点・個人成績の原本、全校の保存ロスター、年度別派生成績キャッシュの**容量と検索コストを別々に測定**する必要がある。

過去記録は引き続き **A方式：スコア・イニング別得点・個人成績** を原本として保存し、打席ごとのイベントを必須としない。

## 変更

`phase2_engine/career_long_full_a_audit.py` に2種類の入口を設けた。

### 1. 使い捨ての完全A形式ベンチマーク

```bash
python -m phase2_engine.career_long_full_a_audit \
  --synthetic-data-root data --schools 2 --years 12 \
  --games-per-school-year 2 --repeats 1
```

実際の `HistoricalMatchArchive`、`CareerRosterArchive`、`CareerPlayerStatCache` を利用して、以下を検証する。

- 2校の架空対戦で**12年度連続のロスター生成・保存**と、回別得点、チーム成績、打撃成績、投手成績をすべて持つ試合を使い捨てのSQLiteへ保存。
- 保存した試合数と完全Option-Aの全項目存在数、年別封印・学校ロスター数・キャッシュ年度数の一致。
- 完全A原本から集計した個人成績と、派生成績キャッシュによる読取りが同じ値を返すこと。
- 学校の過去試合ページと選手成績をraw／cacheから読む時間、Python追跡メモリ、保存元SHA不変。
- 年度ごとの実際のファイル割当サイズ（SQLiteのインデックスやページを含む）と、試合／ロスター／本人ID／派生成績の**原本JSONのバイト数**を区別。
- キャッシュを含む3ファイルの最終実サイズと年度別実測ファイル差分の一致。実行後に使い捨てファイルを削除。

年数・学校数・試合数を増やす機能は既存のベンチマーク境界（学校数は最大100、年数最大100、超大量件数には`--allow-large`が必要）に従う。測定時間・容量を勝手に線形外挿しない。

### 2. 既にあるセーブの読み取り専用フルスキャン

```bash
python -m phase2_engine.career_long_full_a_audit \
  --inspect-matches out/saves/EXAMPLE/historical_matches.sqlite3 \
  --rosters out/saves/EXAMPLE/career_rosters.sqlite3 \
  --derived-cache out/saves/EXAMPLE/derived_player_stats.sqlite3
```

3つの**既存**SQLiteについて、read-only／query_onlyで原本JSONバイト数・年度別キャッシュ由来・ファイル容量を確認。実行前後に3ファイルのSHA-256を再計算して一致を証明する。欠損ファイルを作ったり、キャッシュを新規生成したりしない。実際の保存配置で派生成績キャッシュファイル名が異なる場合は、手元の存在するパスを明示する。

**注意：このモードは全件監査**。原本の全試合・ロスター・キャッシュJSONを走査するため、正式GUIの一覧で毎回実行するためのAPIではない。通常の履歴閲覧は従来の年度・学校・ページ単位の索引検索を使う。

## 出力と証拠の区別

- **論理容量**：保存されたJSONの実UTF-8バイト長をSHAチェックして合計。
- **物理容量**：各年度のSQLite3ファイルサイズ／最終ファイル割当。行サイズや年当たり容量と同一ではなく、SQLiteのページ再利用・インデックスの影響を含む。
- **読み取り**：計測環境の実測時間・メモリ。必ずcacheのほうが高速だとは主張しない。
- **gzipサンプル**：もし表示されても圧縮の仮説にすぎず、保存原本でgzipを有効化したわけではない。
- **整合性**：個別記録SHAと学校年度キャッシュの原本ledgerメタデータを確認するが、`profile_annual_growth`単独では全試合ledgerとcache fact digestを再生成しない。より強い再検証は既存の原本読取契約で実施。
- **対象範囲**：旧ISO A方式のみ。年10000以降の独立v2の全国大会が動いたという意味ではない。
