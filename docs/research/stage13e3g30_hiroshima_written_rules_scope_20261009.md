# Stage 13E-3G-30：2026年広島県高野連「要項・規則文面」と敗者復活の根拠階層分離

調査日：2026年10月9日

## 結論：確認できたのは枠数・日程・県大会の試合方法であり、地区予選の敗者移動規則ではない

広島県高野連公式「硬式部 各種大会」の公開本文を読み直した結果、秋季県大会は32チームで地区別に西部7・北部6・南部10・東部9と**公式に明記**。地区予選の2026年8月22日～9月6日の期間と9月12・13日の予備日も明記されていた。

一方、「県大会」の見出し下にあるトーナメント方式・5回10点／7回7点のコールド・延長10回以降のタイブレーク・継続試合／DH制は、**県大会の試合方法としての根拠**である。これらを別見出しの「地区予選大会」の敗者復活配置、初戦組み合わせ、敗者戦の追加出場資格と同一視してはならない。

同ページは「広島県高等学校野球連盟試合細則及び注意事項」などを**準拠文書として列記**しているが、この参照文言だけでは、細則本文を実際に取得・閲覧できたことや、細則に地区予選の敗者移動規則が書かれていることは証明されない。今回検索した公開本文からは、2026年の「一次何回戦の敗者をどの二位校予選の何番へ送る」などの**一般式・個々の配線図・翌年への継続適用条項を特定できなかった**。存在しないと断定するのではなく「今回確認した公式Web本文には具体的なセレクターを確認できない」とする。

## 残る実装前条件

1. 地区予選の**年度固有の抽選要領・敗者戦への進出条件**の正式資料（別の運営細則、抽選会配付資料や高野連2026原本高精細版）を確認。
2. Stage28の**25試合番号・32個別矢印**の確認待ちを、出典位置の付いた年次資料で一件ずつ消化。
3. 公式移動規則が得られなかった地区は `design_pending` を保持し、代わりに史実DAGを全年にコピーしない。
4. 区域分けの仮ドラフトや「二位校代表数」だけでは試合スケジュール・敗者の次の相手を自動生成しない。FMT025本体・任意順位戦は変更しない。

**Stage30完了の定義：一次資料で実際に確認できる条件と未確認条件を分けた、再利用可能な出典スコープ審査を実装すること。公式敗者移動ルール自体を新規に確定したことではない。**
