# Stage 43G-68：独立v2架空年度の完全A方式・保存容量・個人成績深度監査

作成日：2026-10-12

## 方針

Stage43G-67で監査した **旧A方式（2026年などのISO日付）** と、Stage43G-27〜29で別ファイルに保存する **v2架空年度（年10000以降のゲーム日付）** を混同しないまま、長期的な保存容量と個人成績の整合性を調べる。

- 旧方式：`historical_matches.sqlite3`
- v2方式：`fictional_option_a_v2.sqlite3` ／ `sandbox_calendar_v2.sqlite3`
- 年度ロスター：`career_rosters.sqlite3`
- **v2専用**個人成績キャッシュ：`fictional_v2_player_stat_cache.sqlite3`

年10000以降の架空日程は公式大会の日程ではない。また、「年10000」が保存されていても、2026年から連続して7974年のゲームが進行したことを意味しない。

## 新規の読み取り専用深度監査

`career_v2_long_storage_audit.audit_saved_v2_storage(slot_root, years)` を追加。

**12年度までの明示的な昇順・重複なし年度指定**を受け付け、以下を検査する。

1. カレンダーの元JSONハッシュを照合し、ゲーム日トークン `G{year}:MM-DD` のみを許可。
2. v2各年度の全A試合を既存 `CareerV2OptionAArchive._verified_year` で検査し、全試合JSONのSHA・スコア整合性、封印済みmatch_count／ledgerを照合。
3. 指定年度の学校ロスターJSON SHAを全件検査し、試合に登場する学校の年度ロスターが存在することを確認。
4. v2派生成績の該当年度の学校・選手行を個別SHA照合し、**参加校ごとに `read_year(verify_source=True)` で元の全A個人成績・永続選手ID・ロスター帰属と照合**。未保存キャッシュや片方だけの学校記録は拒否。
5. 年度ごとの元A試合JSON、学校ロスターJSON、v2専用個人成績JSONのバイト数と各行数を記録。異なる年度の選手identityは共通テーブルに格納するため、単一年度の増分へ安易に割り当てない。
6. 4つの元SQLiteファイル、および存在する旧方式SQLiteの**監査前後SHA不変**と物理SQLiteファイルサイズを確認。すべて `mode=ro`／`query_only=ON`で処理。

全件監査は重い。**通常GUIの画面更新では呼び出さない**。長期の実セーブについて12年ごとの任意バッチとして使う。

### 既存セーブに対するCLI

```bash
python -m phase2_engine.career_v2_long_storage_audit \
  --slot out/saves/EXAMPLE \
  --years 10000,10001,10002 \
  --output-json build/reports/stage43g68_v2.json
```

`--output-json`は指定した監査レポートの出力先を作成するものであり、元セーブのSQLiteは更新しない。

## 専用テスト

- 旧方式2026年と**別の**v2年10000の封印済みA試合を準備し、学校ロスターだけは通常の `CareerRosterArchive.advance_and_save` を使って年10001〜10011まで11回進級させる。
- 年10001以降の**架空試合**を各年2試合ずつ追加し、封印して双方の学校についてv2専用統計キャッシュを保存する。対象は年10000〜10011の12年度・v2試合23件・学校年次ロスター24件。
- v2試合、ロスター、カレンダー、独立v2キャッシュのすべてを深度監査し、年度別の論理JSONバイト数／4つのSQLite合計物理容量／読み取り時間・追跡メモリを記録。
- 元試合SHA、キャッシュ個人成績SHA、公式でないカレンダーの元SHAをテストDBで改ざんすると拒否する。
- 対象年度未保存、必要なファイル不在、v2以前の年度・重複年度・13年以上の一括指定を拒否し、読込によるセーブ書き込みがないことを照合。
- 既存Stage43G-27〜29／31の実装回帰、Python全unittest、関東E2Eもmainマージ条件とする。

## 制約

検証した11回のロスター進級は2校分のみ。試合は公式大会エンジンの試合ではなくA形式の合成結果。**全国3000校×100年のゲーム進行性能を証明したものではない。** 物理ファイルサイズは選択年度だけの容量とは限らず、共有ロスターの他年度やインデックスも含まれる。元旧方式の成績とは合算せず、選手の生涯成績としての連結を許可しない。
