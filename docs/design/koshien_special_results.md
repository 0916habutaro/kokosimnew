# 甲子園歴代記録：不戦勝・不戦敗を実施試合から分離する共通設計

## 決定と根拠の位置づけ

日本高野連の大会結果では不戦勝が勝ち上がりとして記録される。一方、歴代の学校別通算への算入は資料によって異なるため、大会裁定の事実と通算集計上の算入基準を分離する。長野県高野連が不戦勝のスコア欄と勝敗欄（○）を別に表示する例もある。出典の「不戦勝」という表現を通常試合の勝利へ書き換えない。

- **基本表示**：公式に認定された不戦勝・不戦敗を、採用根拠のある場合に限り通算勝敗に含める。内訳は保持する。
- **実施試合**：成立した実試合の勝・敗・引分だけを数える。不戦勝の試合数は0。
- **算入根拠の不足**：`unknown` とし、0/1へ自動確定しない。裁定がある事実と通算への算入を区別する。
- **出場回数**：不戦勝・不戦敗で増加させない。出場校としての認定とは別の判断。
- **中止大会**：1918年夏・2020年春は既存どおり出場対象に含め、勝敗0。2020年交流試合は通算から除外。
- **辞退・中止・引き分け再試合**：不戦勝の裁定がない辞退は敗戦扱いしない。引き分け・再試合は成立試合として別々に数える。
- **全国の重複防止**：当時の出場チームの史実と現校の継承通算は別。現校の通算を合算して全国の試合数を計算しない。

## 実装の境界（今回のPR）

`historical_data/koshien_special_results.csv` を、裁定1件1行の専用CSVとして追加する。初回は**ヘッダーのみ**で史実の裁定データを投入しない。既存の `historical_data/matches.csv` は2024〜2026の試合実績基盤であり、2021年の裁定を挿入しない。

| 列 | 内容 |
|---|---|
| `event_id` | 永続・一意の識別子 |
| `kind,year,edition,round_label` | 大会の種別・年・回次・回戦 |
| `winner_school_id,winner_team_name` | 裁定上の勝者。当時校名は必須、現校IDは未照合なら空欄 |
| `loser_school_id,loser_team_name` | 裁定上の敗者。同上 |
| `result_type` | 今回は `walkover` のみ |
| `played` | `false` 固定。得点・イニングを生成しない |
| `win_counted,loss_counted` | 採用する学校別通算への算入：`1`／`0`／`unknown` |
| `source_id` | 裁定と勝敗算入の出典。各算入の判断根拠もREADMEに記す |

`historical_results.koshien.validate()` は新CSVの必須ヘッダー、種別・年度・回次、結果種別、未実施フラグ、学校ID（ある場合のみ）、出典ID、裁定値、重複event_idを検証する。 `summarize_adjudications()` は確定した認定勝敗と未確定件数を別々に返す。学校IDが空欄の相手側を推測して帰属させない。

**このPRでは既存の `aggregate()`・`koshien_records.csv`・`koshien_appearances.csv` に新CSVを自動加算しない。** ヘッダーのみの導入段階で通算の意味を黙って変えないため。裁定を実登録する次工程では、現行W/L/Dと重複しないことを個別に点検してから通算CSVを更新する。

## 次の工程

1. 智弁和歌山（2021年夏対宮崎商）の裁定記録を、学校公式・日本高野連・新聞社の出典に照合して登録する。
2. 智弁和歌山の2025年夏までの実施試合、裁定勝敗を個別再集計して通算へ反映する。現行の夏の既存行があれば値と整合性を確認し、2026年夏は含めない。
3. 津田学園・広陵・松商学園・東北学院・宮崎商、さらに歴史上の辞退案件へ全国共通の方式を順次適用する。

本設計は史実記録専用であり、架空のゲームエンジン・セーブ・学校マスター・正式画面への変更は行わない。
