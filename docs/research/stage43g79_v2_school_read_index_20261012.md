# Stage43G-79：架空v2学校検索の独立読み取り索引

作成日：2026-10-12

## 背景と目的
Stage43G-76で実装したv2学校検索は、原本に学校ID列がなく、SQL JSON1で年度範囲内の全試合を参照する。Stage43G-78の合成完全A原本の監査では、100年度・1000試合の`page`検索中央値31.637ms、厳密検証74.594msだった。実セーブ3000校・100年進行を実証していないため、既存の封印済みv2データに変更を加えず、索引を独立ファイルとして作る方式を用意する。

## 作成・保存の契約
- 明示的な利用者・開発者呼び出し`build_v2_school_read_index(v2_path, calendar_path, index_path, start_year, end_year)`のみで作成する。通常検索時に暗黙作成しない。
- 保存元`fictional_option_a_v2.sqlite3`・架空カレンダー`sandbox_calendar_v2.sqlite3`をSQLite`mode=ro`で読み、封印済み年度、年単位ledger SHA、カレンダーSHA、全試合原本SHAと学校IDを検査する。
- 派生した索引は**第3の独立SQLite**にのみ作成する。学校ID／年度／論理日付／大会ID／試合IDでB-tree検索できるようにする。
- 出典の絶対パス、対象範囲、年度毎のカレンダーSHAとledger SHA、保存試合数、2チーム分の索引登録件数、索引会員レコードのハッシュを保存。
- 初期生成は同一ディレクトリ内のテンポラリSQLiteへ行い、元の原本を変更せず、ターゲット名が既存なら上書きせずに停止する。作り直す場合は別パスを明示して新規作成する。
- 既存の公式ゲーム用GUI・大会進行・旧A方式索引・原本の列定義は変更しない。

## 読み取り・出典検証
`read_indexed_v2_school_page(v2_path, calendar_path, index_path, school_id, start_year, end_year, competition_id, limit, offset, verify_scope)`

- 保存済み年度ヘッダと派生索引の年度集合を突合し、年度の封印・calendar SHA・ledger SHAを比較する。索引の範囲外・異なる原本パスや追加保存年度・未封印なら拒否する。
- `page`：索引から学校・年度・大会を抽出し、**表示中の各試合について元のv2主キーから完全A原本を再取得しSHA／日付／得点・勝敗・所属校を検証**。表示外原本・派生索引全体の改ざん検知は保証しない。件数は派生索引由来であり、必ずしも原本全件の検査済み件数ではない。
- `selected_years`：指定期間の保存済み全学校・全大会の全原本SHAを検証したうえで、同期間の派生学校索引全レコードを原本と一致照合する。索引からの脱落や他校への誤割り当ても拒否できる。これは軽量検索ではなく負荷の高い厳密監査。
- ISO日付には変換せず、`G{year}:MM-DD`をそのまま表示するための試合情報を返す。元の個人成績・イニング別得点・カレンダーを複製・上書きしない。
- 旧A方式とv2は別データ、索引も本番GUIには未接続。v2原本を信頼の根拠とする。

## 性能・制約
- 学校IDの索引を高速照会できるが、ページごとに年度の封印ledgerを再検証するため、年度と試合総数に応じたコストが残る。**定数時間・無制限年度・実全国3000校の性能保証ではない**。
- `page`スコープで派生索引の未表示行や原本JSONの未表示改ざんは検知されない場合がある。検証済み範囲をUIが過大表示しないこと。
- SQLiteは読み取り専用で利用し、索引自体が欠落・古い場合は自動生成・無検証フォールバックしない。呼び出し側が元のStage43G-76の読取APIを明示的に選ぶことは可能だが、出典表示を維持する。
- 読み取り索引の生成は本ステージでは手動明示的操作のみ。Stage43G-77の既存GUIを自動で切り替える実装は含まない。

## 試験
- 10000・10001年度の完全A合成試合で、索引側と既存v2原本APIの表示・件数一致を確認。
- 原本SQLite・架空カレンダーのSHA不変と原本未作成時・未封印時の拒否を確認。
- 索引の会員を削除／すり替えた場合、厳密検証では全件差分を拒否。表示行では原本所属校との矛盾を拒否。
- 原本JSONのページ外改ざんは通常モードで検知済みと主張せず、厳密モードで拒否。
- 専用GitHub Actions、関連するStage43G-76回帰、全Python unittest／関東17校E2Eが成功した場合のみmain反映する。
