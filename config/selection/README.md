# Selection configuration

選抜の選考で使う調整値（game_definition.md §8）。

- `senbatsu_selection_v1.json`: 21世紀枠のくじの重み（都道府県推薦の候補の順位の範囲、公立の倍率、チームの強さの効き方、甲子園から遠ざかっている年数の重み、地区推薦の成績ごとの重み）
- `summer_seed_points_v1.json`: 夏の地方大会の成績シードを秋＋春の成績で選ぶ大会の、ゲームの仮の配点（到達点ごとの点と、秋・春の重み）
- `commemorative_v1.json`: 記念大会（ADR-046）。選抜は回数の下一桁が0か5の年に一般選考の枠を足す（足す数、1地区の上限、地区の単位、大会名）。選手権は回数の下一桁が0の年に7府県の夏の地方大会を2つに分ける（府県と区分の名前、学校の割り振りのファイル、甲子園の出場校の数、大会名）
- `prefectural_seed_fallback_v1.json`: 秋季・春季の県大会でシード校の数が分からない大会の仮の決まり（本大会の出場校の数で8校か4校）

`status=design_default_not_tuned` は実装開始用の暫定値。`tuned_2026_10_26` は実際の21世紀枠（2001〜2026年）の傾向に合わせて調整した値（game_definition.md §8）。値の意味は各ファイルの `notes_ja` に書く。
