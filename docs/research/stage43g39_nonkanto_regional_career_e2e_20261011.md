# Stage 43G-39：東海・四国の実行型E2E（全国地域拡張・第一弾）

作成日：2026-10-11

## 背景
Stage 43G-10の関東8都県17校E2Eでは出場権の地域連携を検証している。一方、全国162大会の2026年プラン・監査は全国を対象としているものの、架空2027年度の能力モデルによる**地区大会試合を同じ年度のセーブに保存→再開→完了→学校/試合詳細を閲覧**まで、関東以外でまとめて検証する工程は不足していた。

Stage 43G-39は第一弾として **東海（CMP000008）と四国（CMP000011）の春季地区大会MAIN** を選択する。双方とも2026マスターの単一MAIN・8校構成で、2026試合日を投影した2027ゲーム日程では3ラウンド分の候補日が存在する。

## 実装
- `phase2_engine/future_non_kanto_regional_main_bridge.py`: 単一MAINと2026年地域所属が確定した非関東春季地区大会だけをホワイトリストに登録。対象は2026構造の東北、北信越、東海、近畿、中国、四国、九州。北海道・関東は参加・資格規則が異なるため除外する。
- `CareerMultiPreviewCheckpointService` に `non_kanto_regional_main_sandbox_v1` を明示的に追加。既存のmode未指定の保存・SHA構造は変更しない。
- 参加校は**全国本番校マスターの正規ID**から各県2校ずつ指定したテスト用サンドボックス。地区外学校、同一地区内でも1都道府県のみの全参加、同一学校重複、年次保存ロスターがない学校を拒否。公式2027出場権や本当の開催地枠を示すものではない。
- 各学校の2026→2027進級・保存済みロスターを試合に利用。2026年度は空のゲーム内封印済みサンドボックスであり、2026実際の試合履歴を改変しない。
- 共通の2027年度セーブで東海・四国地区大会を能力ベース試合エンジンにより日付順に実行し、14試合のスコア、イニング別得点、打撃・投手成績をSQLiteへ保存する。途中ロード再開し、終了後の再ロードでは優勝校が一致することを検証。
- **この2大会だけの試験用年度**を明示的に封印した上で、学校別履歴→試合詳細→保存済み打撃・投手成績を読み取り専用APIで辿り、閲覧による原本SHA変化がないことを検証。
- 保存済みチェックポイントの改変拒否、地域外学校・未登録ロスターの拒否も検証。既存2026年カレンダーを年度投影しているので実在2027年の試合日とは区別する。

## 未実装・後続
- 東北、北信越、近畿、中国、九州については**接続コードの利用可能性**だけを用意し、各地区でのゲーム実行・保存・閲覧E2Eは次の段階で追加する。
- 2027年の実際の予選進出校・開催県枠や招待校を自動認定する仕組みは未実装。2026公式大会の方式を将来にわたり同一と断定しない。
- 本番全国年度運営（各県春秋の結果から地区大会へ自動接続）、過去100年を超える年度索引、最終GUIは別工程。
- Stage 43G-38は47都道府県の**入力マスターの広域監査**であり、Stage 43G-39は関東以外の**保存・再開型試合実行E2E**。両者の検証範囲を混同しない。
