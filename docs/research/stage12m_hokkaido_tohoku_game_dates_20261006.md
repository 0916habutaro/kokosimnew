# Stage 12M-1 北海道・東北 夏地方大会個別試合日構造化

作成日: 2026-10-06

## 目的

Stage 12Lで既知の詳細粒度不足として分離した「夏地方49大会の個別試合日」を、地域ごとの小バッチで実績化する。

Stage 12M-1では以下8大会のみを対象とする。

- 北北海道
- 南北海道
- 青森
- 岩手
- 秋田
- 山形
- 宮城
- 福島

次地域には進まず、この8大会だけで独立して監査・検証する。

## 登録基準

`game_date_list` には「その日に少なくとも1試合が完了した日」だけを登録する。

除外対象:
- 開会式のみの日
- 全試合が雨天等で中止・順延となった日
- 予備日のみ
- 継続試合のみで当日に試合が完了していない日

一部会場が中止でも、別会場で完了試合がある日は実試合日として採用する。

## 結果

8大会すべてを `period_only` 相当から個別実試合日ありへ詳細化した。

- 対象大会: 8 / 8
- 登録実試合日: 合計98日
- 夏地方大会の詳細化進捗: 8 / 49
- 未詳細化: 41 / 49

大会別実試合日数:
- 北北海道 14日
- 南北海道 19日
- 青森 10日
- 岩手 12日
- 秋田 10日
- 山形 11日
- 宮城 12日
- 福島 10日

## 会期末日の実績補正

当初登録されていた公式予定会期より実際の大会終了が後ろへずれた4大会は `end_date` も補正した。

- 岩手: 7/23 → 7/25
- 秋田: 7/20 → 7/21
- 山形: 7/25 → 7/27
- 宮城: 7/26 → 7/28

これにより全 `game_date_list` が `start_date <= game_date <= end_date` を満たす。

## 主な除外例

- 青森 7/12: 全試合順延
- 岩手 7/8: 開会式のみ
- 岩手 7/19・7/22: 全試合順延
- 山形 7/25・7/26: 決勝中止
- 宮城 7/9: 開会式のみ
- 宮城 7/24・7/26: 準決勝中止

## 出典

大会日程の基礎会期は既存の日本高等学校野球連盟 `P2SRC003` を維持し、実試合日の確認用として `P2SRC277`〜`P2SRC284` を追加した。

各追加出典は「令和高校野球 日程と結果」の2026年各地方大会日程・結果ページ。

## 検証

Stage 12M-1専用回帰テストでは以下を検証する。

1. 8大会の実試合日リストが期待値と完全一致
2. 日付が昇順・重複なし
3. 全日付がstart/end範囲内
4. 出典ID `P2SRC277`〜`P2SRC284` が存在
5. 既知の開会式のみ・全面中止日が登録されていない
6. 夏地方49大会が「詳細化8・未詳細41」になる
7. 全162大会では `game_date_list` あり120、空42（夏地方41＋明治神宮1）になる
8. 今回8大会の実試合日合計が98日になる
