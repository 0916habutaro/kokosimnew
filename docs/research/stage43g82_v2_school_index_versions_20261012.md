# Stage43G-82：セーブ単位の架空v2学校索引バージョンの安全な選択

作成日：2026-10-12

## 目的
Stage43G-79の独立学校索引、Stage43G-80の手動GUI切替、Stage43G-81の厳密監査と版別再構築を接続する。**セーブ原本・カレンダー・既存索引を一切変更せず**、版別索引から出典の正しいものを利用者が選べるようにする。対象はTkinter試験GUIであり、実全国大会の年度進行や正式なゲームGUIではない。

## 対象と一覧
- ファイル名形式：`fictional_v2_school_read_index.sqlite3` または `fictional_v2_school_read_index_<version>.sqlite3`。版識別子は英数字で始まる英数字・アンダースコア・ハイフン1〜48文字。
- セーブの`fictional_option_a_v2.sqlite3`と`sandbox_calendar_v2.sqlite3`がある**同一ディレクトリ直下のみ**列挙。別セーブ・上位ディレクトリ・シンボリックリンクは禁止。
- 32ファイルを上限とし、超過時はエラー表示。巨大な候補群を勝手に全検証したり、ファイルを変更したりしない。
- 一覧は**未検証の候補名**にすぎない。表示されたことを「索引正常」「最新」「検証済み」と解釈しない。画面には候補再読込ボタンを設ける。検索画面を開くときの既定の参照先は従来どおり固定名を使い、検索方式は原本JSON1が初期値。

## 明示的な版選択
利用者が一覧から版を選ぶと、Stage43G-81の`audit_v2_school_index_health`を呼び、元の完全A原本・架空カレンダー・封印ledger・全学校の派生索引会員の**全件照合**を実施する。`ready`以外（`extension_required`、`integrity_conflict`、`unsealed_source_years`、`missing_index`等）は拒否する。

- 原本JSON1表示中：厳密検証後に参照予定の索引パスのみ変更。**検索方式は原本JSON1のまま**。使用する場合は`separate_index`を明示的に選ぶ。
- すでに独立索引表示中：厳密検証後、現在の学校・年度範囲・大会フィルタ・検証スコープ・ページオフセットで、新索引から原本SHAを再検証して取得。成功したときに限って参照索引パスと表示ページを同時に更新。
- 不正パス、別セーブ出典、改ざん、封印不一致、年度範囲不足、表示ページ消失などは直前の索引パス・検索方法・ページ・フィルタを保持する。**自動フォールバック・索引の暗黙生成・旧索引の削除は行わない**。
- スロット変更・親画面遷移に成功したときは検索子ウィンドウを破棄し、以前のセーブの索引を持ち越さない。
- 旧A方式の学校試合画面にv2索引版選択は表示しない。v2ゲーム内論理日付`G{year}:MM-DD`を維持。

## テスト観点
- 索引ファイルが1つもないときの安全な空一覧と未作成
- 同じセーブ内の固定索引・別名新索引を列挙し、厳密SHA検証後に手動で切替
- 保存年度を追加した後に古い索引が`extension_required`で拒否され、新版のみ通る
- 別セーブを参照する改ざん索引、パストラバーサル・不正名・リンク・候補数超過を拒否
- 原本・索引のSHA不変と、動作失敗時の表示／フィルタ／モードの原子的維持
- Xvfbによる実Tkの選択・再読込・原本への戻し・セーブ切替・旧Aとの分離
- Stage43G-80 GUI回帰およびStage43G-81原本索引監査の回帰

## 制約
本工程では**索引版の一覧と選択だけ**を提供し、更新済み索引の自動生成・自動選択・本番GUI組み込みは行わない。候補列挙上限は32件、単一索引は最大100年度のまま。実全国3000校・100年の進行や性能保証を主張しない。複数100年度の索引を横断検索する場合は別設計が必要。

## マージ条件
専用CI・全Python unittest・関東17校E2Eを確認し、成功した場合にmainへマージ。日本語のPRと結果報告を維持する。
