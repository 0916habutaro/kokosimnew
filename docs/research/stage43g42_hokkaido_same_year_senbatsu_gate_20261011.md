# Stage 43G-42：同年度センバツ推薦 → 北海道春季10支部予選の証跡ゲート

作成日：2026-10-11

## 背景
Stage 43G-41は2027年の**北海道秋季**10支部予選から20校本大会までの能力シミュレーション・保存再開を検証した。一方、春季北海道 `CMP000004` では、2026年時点の公式ルール `ACR000001` がセンバツ出場校を春季全道大会へ推薦する。支部予選への参加は可能だが、予選通過枠と推薦資格の重複があってはならない。この出場権は2027年度のゲーム内センバツの出場事実からのみ判断し、2026年の推薦校や前年の結果をコピーしない。

## Stage42追加
- `career_hokkaido_senbatsu_gate.py`: **同じ年度のセンバツ `CMP000001` が全32校・31試合を完了**し、保存済みSQLiteの全31試合とMAIN優勝結果が一致する場合だけ、参加32校のうち北海道に所属する正規学校IDを推薦対象として返す。
- 年度の封印は要求しない。同じ2027年度の春に秋大会まで待って封印することは不可能なため、**活動中の年度内で当該大会が完成済み**であることを、全試合ID・勝敗・保存済みA方式成績・行SHA256で証明する。後から別大会の試合が記録されても推薦元31試合の指紋は変わらない。
- `ACR000001` の `same-year source`（年差0）、全国招待大会、`participant_from_destination_prefecture`、北海道01、`allowed_without_qualification_effect`、重複防止契約を厳密に検査。ルール自体が変わったら安全側で拒否する。
- 北海道春季支部予選の参加校は**全10支部について別途明示**。2026年支部マスターからテスト用参加校を選べるが、それを未来の公式加盟校とみなさない。推薦校が支部の参加候補に含まれても、シミュレーション上は予選枠を消費しないように除外する（実際の支部大会参加そのものを否定しない）。
- 15校の支部通過枠と、**同年度センバツで確定した北海道出場校数**を合算し、当年の本大会予定校数を計算。2026年観測値の「支部15＋推薦1＝16」を無条件に2027年へ固定しない。
- 全員の2027年度保存ロスターが存在する場合に限り、2026年の日程をゲーム用に投影した予選→MAINの `FutureCompetitionPreview` を準備できる。支部代表は実際の能力シミュレーションで決まり、試合前に固定しない。
- 未完了センバツ・別年度参照・31試合以外の履歴・保存済み個人成績の欠落・SHA改ざん・所属県の不一致・重複学校・予選枠不足は拒否。

## 明示する未解決点
- 今回の `prepare_hokkaido_spring_after_senbatsu` は**事後準備できるread-only証跡ゲート＋試験用試合プレビュー**であり、同一年度の先行大会が終わったタイミングで別の保存済み大会を動的に追加する機能ではない。
- 現状の `CareerMultiPreviewCheckpointService` は年度開始時に対象全大会のpreviewを準備するため、未終了のセンバツを未来の推薦として扱うことはできない。**センバツ完了→推薦certify→春季previewを後から追加し、同じ年度のチェックポイントへ安全に保存・再開する機能は次工程**。
- 2027年の公式学校名簿・出場校・日付・結果ではない。試験用の学校は実在校マスター由来、選手や結果は架空。
- 正式ゲームGUI、全国162大会の年度自動進行、無制限年度進行は別工程。

## テスト
```bash
python -m unittest discover -s tests -p 'test_stage43g42_hokkaido_senbatsu_same_year_gate.py' -v
```
実際に2027年の架空センバツ32校31試合を能力エンジンで実行し、同一年度の封印前のA方式SQLite保存から北海道出場校を認証する。これを証跡として北海道春季予選を進行し、推薦校のMAIN二重登録を防ぐ。完了後に同年度の大会成績を書き込んでもセンバツ証跡が変化しないことと、不正なソース・参加校の拒否を確認。
