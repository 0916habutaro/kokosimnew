# Stage 13E-3G-6：対戦用ブロックと地理的地区を分離

## 契約の分離

- `area_id`は**学校の恒常的な所属地域**。静岡の藤枝明誠（中部）・沼津東（東部）は変更しない。
- 2026年秋の`bracket_block`は**A～Zの大会年度ごとの対戦区分**。IとJは地域とは別。
- ブロック代表同士の順位戦は、両者の県大会出場資格が既に確定した場合に限り`post_qualification_ranking`。
- 同一地理的地区と異なるブロックを混同しない。`XBLOCK_I_J`は順位戦sidecar専用のイベント表示識別子であり正式な地区マスターには追加しない。

## 広島FMT025

本大会出場32枠の確定前後を試合単位で見分ける。名称に「1位決定」「順位決定」があっても即座にnonblocking化しない。`hiroshima_2026_qualification_guard`は既知の資格決定3試合を保護する。全地区全試合の再照合が終わるまでは2026年の順位戦を0件として**未登録**にする。0件の結果は不存在の証明ではない。

## 将来の汎用化

翌年度以降も対戦用ブロック編成を恒常的地区マスターから導出しない。学校所属を決める地区 scheme とその年の大会blockを分離し、対戦ペア・出場権の事前固定を受け取る汎用sidecar factoryへ拡張する。
