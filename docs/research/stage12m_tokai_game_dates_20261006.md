# Stage 12M-4 東海 夏地方大会個別試合日構造化

作成日: 2026-10-06

## 対象

Stage 12M-4では次の4大会だけを対象とする。

- 静岡
- 愛知
- 岐阜
- 三重

Stage 12M-1〜3で確定した22大会には変更を加えない。

## 登録基準

従来バッチと同じく、`game_date_list` は少なくとも1試合が完了した日だけを採用する。

- 開会式のみ・実試合なし: 除外
- 全試合中止・順延: 除外
- 一部中止でも完了試合あり: 採用
- 継続試合があっても同日に別の完了試合あり: 採用

## 調査上の重要点

### 静岡
既存会期は6/28開始だが、6/28は開会式のみ。実試合は7/4からのため6/28を除外。

### 愛知
既存会期は6/27開始だが、日別スコア上の実試合は6/28から。6/28は複数球場で中止カードがある一方、多数の1回戦が完了しているため採用。

### 岐阜
7/18は県岐阜商－市岐阜商が継続試合となったが、他会場を含め複数試合が完了しているため採用。

### 三重
7/3は開会式のみ。7/4・7/5は一部カードが中止・順延となったが、同日に複数の完了試合が存在するため採用。
