## 用語と記入規則

1. **成績シード**：主催者がシードと指定した学校（前大会順位・新人戦・地区予選の順位等を根拠にする場合がある）。
2. **予選免除**：予選を通らず本大会へ直接出場する権利。シードとは独立する。
3. **初戦回戦／BYE**：1回戦免除は対戦組み合わせ上の事実。シード指定と同一視しない。
4. **枠番号／抽選番号**：公式組み合わせ表のトーナメント上の位置と、抽選時のくじ番号を区別する。例のCSVの配置位置・番号欄は原図未照合なら空欄。
5. **空欄 ≠ 0校、空欄 ≠ なし。** 確認できない数値は空欄。否定（「シードなし」など）も公式根拠なしには書かない。証拠の弱い推測は実値として記載しない。
6. 「本大会参加校数」は校数、チーム数（連合チームを含む）を区別して明記。3位決定戦の開催と地区大会への3位進出枠を混ぜない。
7. 未確定事項は必ず「未確定事項」に残す。2025年秋の大会成績を参照する2026年春のシードは、2025年制度に置き換えたという意味ではない。
8. `school_id` は学校マスターとのID照合をまだ行っていないため空欄。学校名は資料の掲載表記を保持。

### 継続する未確定事項

**本大会シード数未確定74/94行**。うち多くはシード有無自体を確定できていない。シード校数を確認済みのこの段階の16行についても、各県の正式な選定資格・順位の決め方、同地区回避、BYEの割当て、途中再抽選条文などの未解決が残る。**「公式原図で1回戦免除が観察された」だけでは再抽選なし／シードあり／シードなしを断定しない**。全県の抽選細則を確認するまではゲームの本番規則へ自動取り込みしない。

## 未確定事項と後続調査の優先順

- **最優先**：全国94県大会のうち、シード校数・選定元が未確定な県の当年公式要項を収集すること（上記の既確認数を参照）。特に秋季に新チームの新人戦・チャレンジマッチ・支部大会を選定元とする県。
- **最優先**：秋季四国以外の地区大会について、正式な「シード指定」規定、1位校の対戦回避、初戦免除の扱い、同県対戦回避、途中再抽選の有無を抽選細則原本で確認すること。
- **重要**：北海道の道大会へ進む支部別配分・東京の一次予選免除条件と抽選規則の原本確認。春季北海道大会は県行のみとし二重登録しない。
- **重要**：2026年秋季近畿の4府県3位校プレーオフの組み合わせと2027年度にも継続する制度かの確認。年度固有の開催県追加枠は他年度へ固定しない。
- **重要**：各公式組み合わせ原図で、学校別配置・シード階級・初戦回戦・BYE・再抽選の発生を検査する。特に「シードが2回戦から」と記述されている非公式トーナメント自動生成ページは、BYEをシードと誤表記している可能性があるため規則の根拠にしない。
- **重要**：学校別の原資料表記と `data/master/schools.csv` の `school_id` を照合し、確認済みのみ入力する。

## CSV利用上の注意

本調査のCSVは**空欄を含む制度照合の台帳**であり、現状の全国自動組み合わせを直接再現できる完成仕様ではありません。特に県大会の地方区分と秋季地区大会を単純合計して「独立の大会数」と数えないこと。秋季は秋季北海道と秋季東京を、地区レベルと県レベルの双方から参照しています。

夏季調査フォルダ `docs/research/2026_summer_seeding/` と同様、資料のみを管理します。ゲームの `data/`、`config/`、抽選コードは変更しません。途中ファイルや調査スクリプトはPRには追加しないでください。
