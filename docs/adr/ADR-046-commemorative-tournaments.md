# ADR-046 記念大会は「大会の制度は2026年と同じ」の例外にする

- Status: Accepted
- Date: 2026-11-28

## Context

年度の大会表は2026年の大会をひな形にし、大会の制度（出場枠・方式・シード・進出ルール）は
2026年と同じとしている（game_definition.md §8、2026-10-21 の決定）。

実際の甲子園には、回数の決まった年に出場校を増やす記念大会がある
（`historical_data/koshien_entrants.csv` で数えた）。

- 選抜：回数の下一桁が0か5の回（第80・85・90・95回）は36校（通常は32校）。増えた4枠の配り方は毎回違い、決まった基準は見つからない
- 夏の選手権：回数の下一桁が0の回は増やす（第80・90回は55校、第100回は56校で7府県が2代表）。下一桁が5の回は49校のまま

ゲームの中でも、2027年度（2028年3月）の第100回選抜や2028年度の第110回選手権のような年が来る。

## Decision

- 記念大会だけは「大会の制度は2026年と同じ」の**例外**として、その年だけ出場校を増やす
- どの年が記念大会かは**大会の回数**（ひな形の回数＋ずらした年数）で決める。値は `config/selection/commemorative_v1.json`、判定は `phase2_engine/commemorative.py`
- 実際の発表（2028年など）は反映しない。ゲームの決まりのままにする
- **選抜**：回数が5で割り切れる年は一般選考の枠を4つ足して36校にする。21世紀枠2・神宮大会枠1は変えない。
  足す枠は選抜の地区（北海道・東北・関東東京・北信越・東海・近畿・中国四国・九州）ごとの次点を、秋季地区大会の到達点 →
  秋のチームの強さ → くじの順に並べ、上の4地区に1枠ずつ足す（史実に決まった基準がないので、ゲームの決まりで決める）
- 組み合わせは36校（1回戦4試合、28校は2回戦から。第95回・2023年と同じ形）。日程は通常の年と同じ11日に入れる（`config/schedule/national_day_plans_v1.json` の `variants`）
- 大会名に「記念」を入れる（「第100回記念選抜高等学校野球大会」）
- **夏の選手権**（2026-11-28 追記）：回数が10で割り切れる年（第110回＝2028年度、第120回＝2038年度…）は、2018年と同じ7府県（埼玉・千葉・神奈川・愛知・大阪・兵庫・福岡）の夏の地方大会を2つの区分の大会に分け、甲子園を56校にする（1回戦24試合、8校は2回戦から。15日の日程で準々決勝の前までは1日4試合）
  - 学校の割り振りは `data/areas/commemorative_summer_split_2018.csv`。2018年からある学校は2018年の組み合わせ表のとおり、それ以降の学校は同じ市町村の学校の区分（横浜市・大阪市は区まで見る）。出典は二次資料（`data/master/sources.csv` の SRC000400〜406）
  - 区分の大会は、データの行を増やさず、もとの府県の大会の行（日程・ステージ・組み合わせ・シード・代表の決まり・秋の不戦勝の決まり）を区分ごとに写してつくる（`commemorative.expand_rows`）。区分の大会は記念大会の年だけ大会表に入れ、その年はもとの大会を入れない
  - シード・組み合わせ・連合チームは区分の中だけで組む（大会の出場校が区分の学校なので）
  - 秋の県大会のシードは、北・南北海道、東・西東京と同じく、同じ都道府県の夏の地方大会の順位を合わせて使う。夏の代表に秋の不戦勝を付ける府県（千葉・神奈川・兵庫）は、2つの区分の優勝校の両方に付ける

## Consequences

- 記念大会の年だけ、選抜の出場校が36校、試合が35試合になる。画面・記録は出場校の数によらずに動く
- 記念大会の年だけ、夏の地方大会が56、甲子園の試合が55になる
- 記録・評判・画面で2つの区分の大会を1つの府県として合わせる処理は別に足す
