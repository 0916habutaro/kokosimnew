# ADR-045 乱数の生成器は選手1人・1試合に1個にする

- Status: Accepted
- Date: 2026-11-17
- Supersedes: ADR-004（能力ごとに乱数を分ける）

## Context

ADR-004 では能力・守備位置・球種ごとに乱数の生成器（`random.Random`）を1個ずつつくっていた。
試合も1打席ごとに作戦・打球・球数・暴投・盗塁・継投の生成器を別につくっていた。

- 新規開始で約526万個（選手1人あたり約48個）、1試合あたり約390個をつくっていた
- `random.Random` は種を入れるたびに内部の表（624語）をつくり直すので、これが進める速さの大きな部分を占めていた
- 開発中は旧セーブとの互換性が不要になり（2026-10-20 の決定）、「1項目を変えても他の能力が変わらない」ことを守る理由が弱くなった

## Decision

- **選手**：1人につき、名簿をつくるとき（投打 → 名前）に1個、能力をつくるとき
  （守備位置の適性・球種 → 素質 → 能力 → 左右の特性 → 成長の型・潜在能力 → 開始前の成長）に1個。
  どちらも決まった順に引く
  - **どの選手も同じ数だけ引く**。捕手・投手の能力と球種は、その守備位置でなくても引いて捨てる。
    守備位置や監督（新入生の人数）が変わっても、後で引く値（左右の特性・成長の型）の列の位置が変わらない
  - 名前は投打のあとに引く（名前を選び直しても投打が変わらない）
- **試合**：1試合に1個（`match_v1:{competition_id}:{reference_year}:{match_id}`）。打席・作戦・打球・球数・
  暴投・盗塁・継投・投手を守備に回すかは、試合の進みの順にこの列から引く
- **1回だけ引く値**（新入生の守備位置、進級のときの退部、有望な新入生の順番、学校・学年の成分）は
  生成器をつくらず、種と名前空間のハッシュから直接出す（`uniform_for`・`gauss_for`）
- 学年ごとの値（有望な新入生の人数・顔ぶれ）は学年ごとに1回だけ決める

## Consequences

- 同じ種なら同じ結果になる。値は入学のとき・試合のときに1度だけ決まった順で引くので、
  保存・読込や、学校を処理する順で変わらない（#458 と同じ考え方）
- 能力の作り方に乱数を1回足すと、その選手のそれより後の値がすべて変わる。
  名前空間の版（`player_ability_v2` など）は、引き方の意味を変えたときに上げる
- 乱数の引き方が変わったので、同じ種でも前と別のゲームになる（旧セーブは使わない）
