## 2. 追加した機能

`phase2_engine/future_kanto_direct_main_bridge.py`：

- `prepare_future_kanto_direct_main_preview(...)`を追加。対象IDは `CMP000086`、`CMP000088`、`CMP000105`の3件だけ。
- 2026マスターのステージが**MAIN単独**であり、`competition_access_rules.csv`による別出場資格がないことを検証。
- **2027年の参加校は呼出元が明示**する。各県とも今回の回帰テストは8校としたが、正式出場校数が8校という意味ではない。4校以上、同県の硬式加盟学校IDで重複なし、十分な仮試合日が必要。
- 学校ごとの2027年度`CareerRosterArchive`が存在し、学年進級後の恒久選手ID・career_seedと一致することを確認。欠損した学校の2027ロスターを自動再抽選しない。
- Stage43Fの`build_future_season_blueprint`による`game_projection_v1`と既存`TournamentEngine`、`AbilityMatchResolver`を使用。**本戦シード順位は未検証なので付与しない。**

`phase2_engine/career_multi_preview_checkpoint.py`：

- 年次入力に任意の`entry_mode="kanto_direct_main_v1"`を追加。指定された対象県のMAIN単独だけを新アダプタへルーティングする。
- このモードでは`group_entrant_school_ids={}`が必要。前年秋出場資格を別大会の直接MAINへ流用する`prior_source_competition_id`も禁止。
- **従来の`entry_mode`無しの入力はそのまま従来の前年秋予選免除アダプタへ通す**。保存済みStage43G-2/3/4の年次plan SHA-256が変わるような一律フィールド追加はしない。
- 異なる大会方式を同じ年度セーブの一覧に並べても、旧年度sealed履歴を保持し、日付順に2027年度のA方式試合を一括保存・ロードできる。

## 3. 年次セーブ内の仮大会テスト

`tests/test_stage43g5_direct_main_kanto.py`：

- 2026ゲーム内年度を封印、3県各8校の2026ロスターを2027へ進級保存。
- 3県のMAINを同じ`career_multi_previews/2027.json`から一括起動。各8校によるMAIN、各県の学年継続・seedなし・仮日程の来歴を検証。
- 2027の4月11日から実試合を進めてA方式SQLiteへ記録。試合結果、試合日、既存2026の歴史・本編手動セーブが保持されることを確認。
- セーブからロードし、日付順の続きと同一のブラケット・勝敗を復元。3大会の完了結果、計21試合のA履歴、再開後の優勝校の一致を検証。
- 神奈川・東京・千葉の異方式をdirect MAINへ無理に付け替える入力、未知モード、地区入力の混入、他県校・未知校、欠損ロスター・違うseedを拒否。
- JSON入力を変更された場合のチェックサム拒否、従来モードをdirect MAINへ自動変換しない互換性を監査。

## 4. 追加の準備が必要な対象と次工程

- 千葉：前年秋の封印済み上位8校を地区予選から免除し、前年結果から2027地区代表を組み立てる経路はStage43Fで既に検証済み。**関東春への上位3校の境界**は同率3位の扱いを確定し、必要なら独立した順位決定試合・保存・試合日を年度ランタイムで実装する。
- 東京：前年秋の2026公式大会マスターが欠落しているので、試験用に**明示・封印済みのゲーム秋大会IDを使用**し、2027年度複数大会リストへの安全な参加とA履歴の実戦検証を行う。
- 神奈川：センバツ大会の参加校と、2027春の予選免除・本戦直行の条件を検証する新アダプタが必要。出場者を手入力で断定したり、自動的に0校と解釈して資格を消さない。
- **Stage43G-6以降**：上記3県の条件解決と関東8県全体の年次進行。各都県のMAIN上位2校＋千葉の有効な3位校で17枠を確定後、春季関東`CMP000006`の試合・歴史・セーブ再開を通しでE2E検証する。
- 2026方式を将来年の本物の大会結果・公式規則として扱わず、正式GUI・年度2028への自動更新・全国162大会の進行はまだ実装しない。

**今回の完成範囲は「栃木・群馬・山梨の2027試験用本戦を2027複数大会セーブへ接続する」こと。春季関東17校の実ゲーム確定までの到達は別工程。**
