# Stage 13E-3G-26：広島秋季西部の可変参加校数・出場枠マクロ試作

調査・実装日：2026-10-09

## 概要と変更の意図

Stage25では2026広島秋季西部の史実「18校・25試合・32学校別進行接続・7県出場枠」を全件照合した。ただし連盟公式PDFの試合番号と敗者の個別移動矢印は未完全確認であり、その史実DAGを翌年度の抽選規則として採用することはできない。

今回の設計は「**学校数が変動しても、同じ形の代表選出計画を安全に試せる**」ことと「**史実を規則と取り違えない**」ことを両立する。既存のseed付き `hiroshima_annual_zone_draft.py` を再利用し、仮想学校IDでの均等ゾーン配分と、利用者が**別途確定した**一次1位・二位校・横断決定戦勝者の枠保存監査のみを行う。ゲームの試合生成・抽選矢印・本体FMT025を改変しない。

## 2026年秋西の観測マクロ（2027年以降の公式規定ではない）

| 要素 | 2026秋西の観測値 | 試作上の扱い |
| --- | --- | --- |
| 一次ゾーン | A・B・C・D | 必要に応じて年度別テンプレートが明示する |
| 初期参加数 | 18校 | 仮想入力の校数18・19・23等へ変更可能 |
| 一次1位の県出場 | 各ゾーン1校＝4枠 | 各ゾーンが1枠を出すという試作用ルール |
| A・Bの二位校 | 各1校が直接出場＝2枠 | 直通ゾーンを明示 |
| C・Dの二位校 | C/D横断決定戦勝者1校＝1枠 | 2ゾーンを1ゲートとした明示的な候補関係 |
| 本戦進出合計 | 7校 | 4＋2＋1の保存則を確認 |

公式根拠：広島県高野連の2026年度秋季西部公式画像（マクロ構造のみ）
- https://hiroshima.hhbf1950.or.jp/大会関連/硬式部各種大会
- https://drive.google.com/file/d/1VxVW_r_L5MwnP3hkqZToGe3o5StK5NQ-/view?usp=sharing

2026の個別試合・学校結果はStage25で保存済み。画像から全カードの公式試合番号・敗者移動矢印を解読したとは主張しない。

## 新しい仕組み

- `phase2_engine/hiroshima_variable_qualification_macro.py`：`MacroTemplate`、`MacroDraft`、`MacroAwardResult` と純粋関数群。
  - `validate_macro_template()`：一次ゾーン、二位校の直接出場と横断決定戦の**すべての二位校出口が1つずつ**であることを確認。C・Dを横断に使いながら別の代表へも進める二重割当を拒否。
  - `draft_qualification_macro()`：外部から与えられた学校/合同参加単位のユニークIDをseed付きで均等に**仮**配分。追加のMAIN直通免除がある場合は参加校集合との重複を禁止。各ゾーンに一次1位・二位校候補の計2単位以上を要求。
  - `evaluate_declared_macro_awards()`：一次1位、二位校、横断決定戦勝者を**外部から指定**してもらい、実際にそのゾーンの参加者であるか、二位校と一次1位が別人か、総出場数に超過・不足・重複がないかを検査。**勝敗や敗者送り先を生成しない**。
  - 5ゾーン・6ゾーンの形式も**仮想例**として検証するが、広島の別地区や翌年度にこの方式を自動適用してよいという意味ではない。
- `data/competitions/2026/hiroshima_macro_template_stage13e3g26.csv`：2026年度秋西の観測マクロ1件と、汎用公式規定証拠なし／live不可フラグを保存。
- `phase2_engine/hiroshima_stage13e3g26.py`：Stage25の25試合・32接続監査、Stage24の9フェーズ公式画像、今回の観測マクロテンプレートと18・19・23仮想校のゾーン配分を横断監査。
- `tests/test_stage13e3g26_variable_macro_sandbox.py` と `tests/test_stage13e3g26_integration.py`：seed再現性、校数可変、直通免除、外部勝者検査、二重進出防止、前年/翌年度の公式資格の誤主張・本体runtime誤解禁を拒否。
- `data/research/2026/research_pending_queue.csv`：研究キューの更新。

### 汎用化の境界

**seed付きの仮配置**と**実際の連盟抽選規定**は別物。試作の `WEST_2026_OBSERVED_MACRO_EXAMPLE` という定数名も、観測例であって翌年度の自動正式ルールではないと明記する。

勝者の計算に必要な対戦カード・敗者復活の配置・実際の試合スコア・日程を、この機能は生成しない。全ての出力に `live_fmt025_runtime_enabled=False` を維持し、代表確定後の順位決定戦 `design_pending` の解除もしない。

## 次工程：Stage 13E-3G-27の候補

1. 高解像度PDF/原本を取得したら、2026秋西の25試合の公式番号・勝敗矢印をStage25の史実台帳へ独立証拠としてひも付ける。
2. 実際の敗者移動セレクターを、公式組み合わせ図の年度限定DAGとして実装。その後、将来年度のランダム抽選で再現できる部分のルールを別途検討。
3. 北部・南部・東部、春季についても公式画像の読める範囲と年度ごとの代表枠差を調査する。
4. 正式な出場ルールが確認できるまでは、今回の試作を本番FMT025へ自動接続しない。

**達成判定**：可変参加校数、seed再現、二位校の直通/横断ゲート設定、枠保存検証を2026秋西の観測マクロを用いた独立試作として実装・テスト。公式敗者復活抽選規定の一般化は未達。
