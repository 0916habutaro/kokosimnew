# Stage 43G-52：同一年度の選抜・愛知5地区・三重3地区の同時実行と保存再開

作成日：2026-10-11

## 既存の段階
- Stage43G-50：同年センバツ31試合の保存記録を全件照合し、愛知・三重の予選免除権を認証する読み取りゲート。
- Stage43G-51：年度最初の試合前に、センバツ32校と愛知5地区（FMT010〜14）、三重3地区（FMT016）の出場校を凍結。免除校は地区予選に参加させない。

## この段階の実装
- `future_tokai_concurrent_bridge.py` を追加。Stage43G-51の凍結済みマニフェストのみを受け入れ、愛知FMT010〜14の地区予選48枠、三重FMT016の地区予選25枠にセンバツ由来の直接県本大会校を加える。各県MAINへ引き渡される学校は実際の予選勝ち上がり結果により確定。2026マスターの学校所属（特に三重の8下位地区）の再検証、重複・未保存選手の拒否を実施。
- `CareerMultiPreviewCheckpointService.add_tokai_concurrent` で、最初の試合日以前、前年封印済みledgerと当年度セーブidentityが不変な場合のみ両県を同一セーブへ追加。追加契約`tokai_concurrent`に凍結マニフェストSHAと初期組み合わせdigestを保存。
- 新規年度セーブを途中から修正するのではなく、3/19のセンバツと3/20の愛知・三重の地区予選を、日付順`play_next_date`で同時に進行。センバツ免除校は地区予選へ入れないため、同日二重出場を避ける。
- `load`は選抜および初期県大会を同じseed・凍結契約で再構築したうえで日付順に再生し、A方式の対戦・スコア・回別得点・打者投手成績を元SQLiteと比較。
- Stage43G-51 `audit` は試合開始済みの両県が凍結済みの校・組・免除対象と一致することをチェック。センバツ全31試合完了までは暫定、完了した場合だけStage43G-50の試合保存証拠で免除参加校を事後認証。

## 非対応と後続
- 現在の2026参考日付を2027年の**架空ゲーム日付**として使い、公式2027年の加盟校・抽選結果・日程を主張しない。
- 東海大会8校全体の資格認証に必要な岐阜・静岡・愛知・三重を**同一セーブ**で動かし、東海地区MAIN7試合を行う結合E2Eは次のStage43G-53で実施する。Stage43G-52では選抜・愛知・三重の複数大会を単一セーブで進めることを対象とする。
- センバツに出場する同一学校が別の春季地区予選に誤って登録された場合には拒否。選抜32校決定ルールの自動推定や、通常ゲームの正式GUIへはまだ統合しない。
