# Stage 13E-3G-38：広島秋季西部5校の観測略称と正式学校名の根拠照合

調査・実装日：2026-10-10

## 背景

Stage37では、2026年秋季広島西部25試合・18校の二次結果に登場する学校名を、学校マスターの`federation_name`完全一致または既存照合済みの別名「山陽」「広島城北」へ安全に対応付けた。正式名称・学校IDが未検証の校名を類推で埋めることは禁止した。

Stage38では実際の高校野球大会掲載校名と学校・行政の正式名称を別証拠として調査し、**既存Stage37の照合結果を変更せず、未照合の校名に限り根拠付き候補を追加検査する**。

## 実装した厳格な2段階判定

`phase2_engine/hiroshima_stage13e3g38_reviewed_aliases.py`

1. Stage37の18校照合結果を先に読み、**既に確認した学校IDは変更しない**。候補の正式名がその学校の正式名と衝突するなら保留ではなく監査エラー。
2. Stage38で調査済みの**5校の観測名・正式校名・県34・年度2026・2つの根拠URL**が登録済みのレビュー定数と完全一致するか検査する。知らない略称や無断追加行を拒否。
3. `data/master/schools.csv`の広島県学校で、候補の正式校名と`official_name`が**文字列完全一致する唯一の1校**だけを候補とする。`federation_name`の前方一致や「商」「工大」など類似名・市立商業との混同は認めない。
4. 2026年度`hardball`、`membership_status=active`で**ただ1件の**野球プログラムと結び付くことを要求。
5. 学校IDが他の観測名に使用されていた場合、同名正式校が複数ある場合、正式名や2026加盟条件が一致しない場合は**未照合のまま保留**。学校IDを創作しない。
6. この照合結果をStage35～36の試験GUI読取モデルに反映し、照合済み学校だけ正式校名・`school_id`・`program_id`を表示・検索可能にする。SQLite、通常のBrowseRepositoryは変更しない。

今回の照合は学校そのものの識別であり、春秋県大会の資格付与ロジック・年度ルール・試合の公式矢印とは無関係。

## テスト・検証

`tests/test_stage13e3g38_hiroshima_reviewed_official_aliases.py`は以下を検証する。

- 模擬マスターで正式校名候補5件が安全に一致するときだけID採用
- 県外、2025年度、硬式未加盟、同一校名複数校、重複プログラム、既に使用中の学校IDを拒否
- 同名の別学校（とくに広島県立商業／広島市立商業）へ自動で結び付けない
- 根拠URL・正式校名・年度・証拠区分の改変で不正リンクが生じない
- Stage37で確認済みの学校IDは上書きしない
- 2026秋西18校の実ファイルとGUI表示に反映し、未照合校の学校詳細を開かない

`audit_2026_hiroshima_stage13e3g38()`は、Stage37までの件数、追加照合できた名称、なお未解決の名称を別に返す。5件の資料調査は**5件の学校ID確定を意味しない**。採否は現在の学校マスターに照らした機械監査の結果に従う。
