# Stage 43G-7：春季千葉県大会の関東第3代表決定戦をゲーム内2027セーブへ接続

作成日：2026-10-10
直前工程：Stage43G-6 PR #147（main反映済み、Python 3.12全1,388テスト成功）。
適用区分：**2026年の公式大会構造を借用した、2027年以降のゲーム内sandbox試合**。2027年の開催県・第3代表枠・公式試合日は検証されていない。

## 1. 根拠と年度の違い

千葉県高野連の2026年公式行事予定では、5月2日に県大会準決勝、**5月3日に関東大会出場校決定戦および県大会決勝**が設定されている。

- 千葉県高野連「令和8年度行事予定」：https://chbf.or.jp/calendar-20261-20273
- 千葉県高野連「令和8年度第79回春季千葉県高等学校野球大会について」：https://chbf.or.jp/archives/oshirase2/%E4%BB%A4%E5%92%8C%EF%BC%98%E5%B9%B4%E5%BA%A6%E7%AC%AC%EF%BC%97%EF%BC%99%E5%9B%9E%E6%98%A5%E5%AD%A3%E5%8D%83%E8%91%89%E7%9C%8C%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1%E9%87%8E%E7%90%83%E5%A4%A7%E4%BC%9A-2
- 大会結果：2026年5月3日、**拓大紅陵 6-4 八千代松陰**。これにより拓大紅陵が関東第3代表となった。https://www.hb-nippon.com/tournaments/1451
- 千葉県高野連の春季関東大会公式案内：2026年関東大会は17校、千葉開催。https://chbf.or.jp/archives/oshirase2/%E4%BB%A4%E5%92%8C%EF%BC%98%E5%B9%B4%E5%BA%A6%E7%AC%AC%EF%BC%97%EF%BC%98%E5%9B%9E%E6%98%A5%E5%AD%A3%E9%96%A2%E6%9D%B1%E5%9C%B0%E5%8C%BA%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1%E9%87%8E%E7%90%83%E5%A4%A7%E4%BC%9A

**結論：2026の第3代表は準決勝敗退校リストの順番ではなく独立の代表決定戦の勝者である。**

2026年千葉開催ゆえの3校枠・5月3日の試合日を翌年も史実として使うことは禁止する。ここではStage43G-4の既存の**2026方式を将来年へ投影するゲーム専用契約**を、実試合で実行できるようにする。

## 2. 実装

新規：phase2_engine/chiba_third_place_checkpoint.py

公開API：ChibaThirdPlaceCheckpointService(multi).start(slot_id, year=2027) / load(slot_id, year=2027)。

1. Stage43G-2の年度共通セーブをロードし、千葉CMP000092のMAINが完了していることを要求する。2027選手ロスターは継続保存済みのもののみ使う。
2. MAIN全試合の保存済みA方式SQLite履歴を検証し、準決勝2試合の敗退校を抽出する。勝者・順位表の配列順やユーザー指定の学校リストによる代替は不可。
3. 2026日程に由来するゲーム仮日付**当年5月3日**を使用。MAINがこの日までに終わり、関東地区大会のゲーム仮開始日5月16日より前であることを検証する。
4. 2027継続選手のAbilityMatchResolverで**実試合**を1試合実施。PLACEMENT/THIRD_PLACEを設定し、イニング別スコア、打者・投手成績を含む既存A方式SQLiteへ、県大会MAINと同じyear/plan_fingerprintで追記する。
5. career_placement_previews/{year}_CMP000092_third.jsonへ試合証拠・source SHA・試合SHA・勝者を保存。loadではMAINから試合を再生成して全項目照合し、SQLiteへの同一行再同期を実施する。JSON保存直後のSQLite追記失敗時にはロードで安全に追記可能。
6. 戻り値のmatch_idを既存Stage43G-4のplacement_decider_match_idsに渡せば、試合記録・対戦校・時系列・改変検知に合格した場合に限って千葉3枠が認証される。他7都県の結果を勝手に確定することはない。

既存Stage43G-2/4セーブ形式、2026封印履歴、シードルール、センバツ推薦ゲートには変更を加えない。

## 3. 回帰テスト

tests/test_stage43g6_chiba_tokyo_multisave.pyに追加：

- 千葉MAIN未完了時は第3代表決定戦の作成を禁止
- 2026秋の封印 → 2027千葉・東京年度共通セーブ → 千葉MAIN完了 → 2準決勝敗退校の決定戦 → A方式SQLite保存 → 春関東第3代表資格の検証 → JSON/SQLite決定論的ロード
- 同一年次の第3代表決定戦を二重作成しないことと、SQLite記録SHAを改変した場合の拒否

**確認が必要な制限：** 2027千葉の第3代表枠は公式確認済みではない。Stage43G-4の17校ゲートでは引き続き神奈川センバツ参加校や他の未実行県を保留し、全17校を自動確定しない。本工程は正式な全162大会の年度進行・GUIではない。
