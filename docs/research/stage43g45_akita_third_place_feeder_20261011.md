# Stage 43G-45：春季東北大会・秋田県3位出場枠の保存試合認証

作成日：2026-10-11

## 位置付け
Stage 43G-44では、徳島・香川・愛媛・高知の春季県大会の上位2校ずつを保存済みゲーム結果から認証し、四国大会を完走できた。ただし3校以上の進出枠では、トーナメント準決勝敗退2校を順位だけで3位／4位に割り当ててはならない。

2026年春季東北地区大会 `CMP000005` は青森3、岩手2、宮城2、秋田3、山形2、福島2の計14枠。今回**秋田 `CMP000078` の3枠目だけ**を、保存済み3位決定戦によって検証する。

## 実装と検証
- `future_akita_direct_main_bridge.py`：秋田県春季MAINを、実在校IDの明示8校で2027年ゲーム用仮日程により能力試合実行するアダプタ。2027年公式出場校・実際の開催日程・本来の県大会出場校数を確定したものではない。
- `career_multi_preview_checkpoint.py`：四国／関東の既存モードに影響を与えず、限定 `akita_direct_main_v1` を追加。秋田8校と独立の徳島8校を同一年度セーブでプレイし、14試合のA方式成績を保存・再開。
- `chiba_third_place_checkpoint.py`：既存の千葉3位決定戦の保存契約を維持し、秋田専用 `AkitaThirdPlaceCheckpointService` を追加。**秋田県MAIN完了・7試合の保存照合・準決勝敗者2校の確定**が終わってから、ゲーム用に2026年の秋田3位決定戦日（5月24日）を2027年へ投影し、能力スコアで3位決定戦を1試合実行。保存済み選手のA方式（イニング得点、打撃・投手成績）をSQLiteと独立チェックポイントに記録する。
- `same_year_regional_feeder_gate.py`：地区大会14校のマスター構造を検証し、秋田だけは**保存済み3位決定戦ID**が存在し勝敗／学校ID／準決勝敗者／試合日／SHAが検証できる場合に限って、決勝進出2校＋3位戦勝者の3校を認証。千葉 `CMP000092` の既存処理は維持。無関係な県・地区の3位記録転用を拒否。
- 専用CI：県大会途中の3位登録拒否、準決勝敗者の自動3位認定の拒否、全15試合の保存、3校認証、他5県未完了のための**東北大会自動開催拒否**、異県学校・偽試合ID・保存履歴改ざん・重複決定戦の拒否、元年度ledger・2027年度計画指紋を確認。

## 2026公式試合日との相違に注意
2026秋田県の日程では、5月24日が3位決定戦で、決勝が5月25日。この工程の2027ゲーム内サンドボックスは参加8校の早期ラウンド投影（5月8日～）でMAINを完了し、その**後に**5月24日の3位試合を追加する。公式2026年トーナメントの正確な日付・同日並列の進行を再現したとは主張しない。
正式な年度エンジンでは、準決勝終了時に3位戦と決勝をそれぞれ予定日に進行できるようにする必要があり、後続で調整する。

## 残課題
- 秋田3校の証跡だけでは**春季東北大会14校はまだ確定しない**。青森3位も独立に証明する必要があり、岩手・宮城・山形・福島の県大会結果も必要。今回の `all_feeder_results_verified` は常に false。
- 青森は春季 `SEED_EVENT`、岩手・宮城・福島は支部予選とMAINを持つため、秋田の単一MAIN入力を無理に転用しない。
- 2027公式出場権、実際の出場校、現実の試合結果、全国162大会の年度自動進行、正式ゲームGUIは未完成。
