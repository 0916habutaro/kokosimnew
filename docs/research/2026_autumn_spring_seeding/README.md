## 確度の区分とゲームでの扱い（ユーザー決定）

| `ゲームでの扱い` | 県大会 | 地区大会 | ゲームへの採用条件 |
|---|---:|---:|---|
| **確定の規則** | 14 | 0 | 元CSVの確認済みシード数・選定条件を使用 |
| **暫定値をそのまま使う** | 48 | 3 | 元CSVに記録した数値をそのまま使用し、暫定であることを保持 |
| **仮の決まり** | 32 | 15 | シード総数空欄に下記のゲーム用条件を適用 |

**シード校数が空欄の大会の仮決まり：本大会の出場校が32校以上なら8校、32校未満なら4校。前の大会の上位から選ぶ。** この文言はユーザー決定の**ゲーム内ルール**であって、実在大会の成績シード制度が存在するとの主張ではない。`ゲーム用の決まり・補足`列にも個別大会の採用内容を収録。直前大会が別段階を持つ場合、ゲーム実装時にはその大会で利用可能な直近の成績順位を用いる。**BYE校・予選シード校・予選免除校・正式成績シード校は同義ではない。**

**確度の読み方**：高野連の原図・要項で直接確認した「人数・枠・試合・配置」は2026年の観測事実。報道・過年度から推測する継続性や選定理由は暫定。元CSVの「出典の確度」「未確定事項」を優先する。数値があってもその制度が毎年必須と確定したとは限らない。

## 県大会の3位決定戦（2026-11-12 追加）

準決勝で負けた2校の順位（地区大会の3校目・4校目、シードの3位）を決める3位決定戦の有無を、2026年の大会で調べた。正本は `data/competitions/main_tournament_engine_policies.csv` の `third_place_*` 列（出典は `data/sources/phase2_sources.csv`）。この表の `3位決定戦` 列の空欄も同じ内容で埋めた。

- `third_place_match`：`yes`（2026年に実施を確認）・`no`（実施していないことを確認）・`unknown`（未調査、または分からない）。推測では埋めない
- `third_place_day`：`final_day`（決勝と同じ日）・`before_final`（決勝より前の日）・`unknown`（分からない）。`third_place_date_2026` は記事・原図で確かめた日付。決勝と同じ日なら `data/schedules/2026/season_calendar.csv` の最終日と一致する（日程の表には日を足していない）
- 秋季に地区大会へ3校以上が出る26府県（東北6・北信越5・東海4・大阪・兵庫・中国5・四国4）は、すべて2026年に3位決定戦があった。日付が分かったものは、決勝と同じ日だった。福島・鳥取は日付が分からない
- 地区大会の開催県で4校が出る大会（秋季新潟・秋季鳥取・春季長野・春季島根）も、3位決定戦で3位・4位を決めていた
- 3位を出場校決定戦に送る近畿の4府県（滋賀・京都・奈良・和歌山）、地区大会が2校の秋季群馬（2026年は開催県で3校）・福岡でも実施。秋季千葉は原図に3位決定戦がない（`no`）
- 春季は、地区大会に3校以上が出る大会（青森・秋田・千葉・京都・鹿児島）と、2校以下でも3位決定戦を確認した大会（岩手・宮城・山形・福島・岐阜・奈良・鳥取・福岡）を記録した。残りの春季の大会は調べていない（`unknown`）
