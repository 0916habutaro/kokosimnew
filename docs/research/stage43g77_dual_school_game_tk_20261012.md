# Stage43G-77：旧A方式・v2の学校別試合検索をTk試験画面に出典別接続

作成日：2026-10-12

## 対象と導線
- 既存 `CareerHistoryTkPilot` の「保存済み年度 → 学校」画面から、該当年度の保存原本に合った学校別試合検索画面を開く。
- 旧A方式：`historical_matches_legacy_iso`（年度1〜9999）。従来の「旧A方式：学校の過去試合を検索」ボタンを維持し、v2画面では無効。
- v2：`fictional_option_a_v2`（年度10000以上）。新設「架空v2：学校の過去試合を検索」ボタンを使い、旧A方式画面では無効。
- 有効化は`source_verified=True`の学校画面に限る。ユーザー入力文字列で所属出典を推定せず、セーブの保存済み学校IDと年度を初期値として使う。年度候補ヘッダのみの画面では両ボタンを無効化する。

## 画面・read model
試験Tk画面の表レイアウトを再利用するが、保存レコードの出典を画面上で明確に分離する。
- 共通列：年度・試合日・大会ID・試合ID・対戦校ID・得点・勝敗。1ページ30件、前後移動。
- 旧A：`YYYY-MM-DD` ISO日付、`filtered_window`で選択した学校・年度・大会の全件SHAを検証する。
- v2：`G{year}:MM-DD` ゲーム内論理日付、`selected_years`で選択期間内に保存された**全学校・全大会の完全A原本**を検証する。
- 両者の `page` モードは表示ページだけのSHA検証を意味する。特にv2では学校所属がJSON内部にしかないため、選択されない改ざん済み原本の存在や総件数を保証できない。v2の検索はJSON1走査であり学校ID先頭索引と同等の性能ではない。
- v2の年度範囲はStage43G-76で最大100年。旧Aの原本・v2の原本・架空カレンダー・キャッシュを移行・改変しない。

## 安全な遷移
- `CareerV2SchoolGamePager` は取得結果の出典、年度、学校、SHAスコープなどを再照合して初めて状態を反映する。
- 範囲外年度、誤った検証スコープ、SHA不一致時には前回の表示とフィルタ値を保持する。
- 親画面の履歴遷移に成功したとき、またはセーブ切替時に、旧A/v2どちらの子検索画面も破棄する。セーブ間で以前の検索状態・学校IDを共有しない。
- 本番用GUI・大会の年度進行処理は変更しない。未保存の試合や公式大会順位・歴代記録を推測しない。
