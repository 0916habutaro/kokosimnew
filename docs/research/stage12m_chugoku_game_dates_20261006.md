# Stage 12M-6 中国 夏地方大会個別試合日構造化

作成日: 2026-10-06

## 対象

Stage 12M-6では次の5大会だけを対象とする。

- 鳥取
- 島根
- 岡山
- 広島
- 山口

Stage 12M-1〜5で確定した32大会には変更を加えない。

## 登録基準

従来バッチと同様、`game_date_list` には少なくとも1試合が完了した日だけを採用する。

- 開会式のみ: 除外
- 全試合中止・順延: 除外
- 一部中止でも完了試合あり: 採用
- 日付一覧上で完了スコアを確認できた日: 採用

## 調査上の重要点

### 岡山
既存会期は7/9開始だが、会期初日は開会式のみ。日刊スポーツの実試合日は7/11からで、決勝7/27まで13日を採用。

### 広島
7/4の日別スコアは国泰寺－庄原格致が「中止（試合開始前）」で、当日の完了試合を確認できないため除外。
7/5・6・7・10・11・12・15・16・19・22・26・28は日別ページで少なくとも1試合の完了スコアを確認した。

### 鳥取・島根・山口
日刊スポーツの日付一覧と「令和高校野球 日程と結果」を照合。各掲載日に完了試合があり、全面中止・継続のみの日は確認されなかったため、掲載日をそのまま採用。
