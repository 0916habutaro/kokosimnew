# Stage 13E-3G-21：広島地区予選・敗者の移動条件とFMT025実行解禁の証拠ゲート

作業日：2026-10-09

## 概要

Stage13E-3G-20で公開子大会のゾーン名（春秋計38一次ゾーン）と87子大会・二位校決定戦35件・地区内横断の県大会出場決定戦14件を構造化した。2026年二次公開結果223試合→進行接続287件のうち、**一次予選で敗れた学校・合同参加チームが次の敗者復活試合へ登場した121件**について、学校表示・敗戦した回戦・次の試合・日付を独立証拠CSVとして保存した。

この段階で証明されているのは**2026年にその学校が次の試合を行ったという観測記録**であり、別の学校・年度でも同じ敗者移動になるという大会の抽選規定ではない。

| 条件 | 登録件数 | 備考 |
|---|---:|---|
| 一次敗戦→後日の敗者復活 | 121 | 2026二次結果から参加校単位で追跡 |
| 前後双方にブロック表示がある接続 | 103 | これらはすべて表示ブロック名が同一 |
| 表示ブロックの片方または両方が不明 | 18 | 元の資料から補完するまで保留 |
| 敗者復活代表決定戦敗戦後の追加ゲート | 6参加単位・5試合 | Stage18/19の既存観測を再利用 |
| 公開二位校イベント | 35 | 終了校・次ゲートの移動条件は未確定 |
| 公開地区内県大会出場決定イベント | 14 | イベント名は実際の抽選接続と同値ではない |

8地区の観測一次敗戦→敗者復活の内訳：春西13、春北13、春南18、春東17、秋西14、秋北12、秋南18、秋東16。

## 調査の根拠階層

1. **公式一次資料で確認が必要なルール**：年度別の大会組み合わせ本文、各初戦の勝敗で敗者が移る先、二位校イベント内の組み合わせ、クロスゾーンへの候補の送り元、敗者復活で敗れた学校の追加代表決定ゲートへの参加条件。
2. **公開大会掲載インデックスにより確認した子大会構造**：SportsOnlineの春43・秋44の87予選イベント。名前付きの一次38・二位校35・クロスゲート14の存在。掲載イベントのタイトルだけで個々の学校の敗戦後の移動先は決めない。
3. **二次結果により確認した出場履歴**：223試合からの287観測接続、うち121一次敗戦後の敗者復活継続と6敗者復活敗戦後の再挑戦。これは**結果の連続性**であり、未来年度の抽選生成規則の証明ではない。
4. **ゲーム実装上の仮設計**：未確認ルートに対する提案、試作用のseed付き参加校ゾーン均等仮配置。公式抽選表の再現を主張しない。

別資料で、春季西部の4ブロックから各1位が県大会へ、敗者復活から2校が追加、選抜出場の崇徳が予選免除であるという大枠は独立して裏付けられている（高校野球ドットコム「春季広島大会地区予選の組み合わせ決定」2026-02-28： https://www.hb-nippon.com/articles/11302 ）。ただしこれは出版社の公開記事であり、公式PDFの敗者移動の矢印を確認したことにはならない。

高野連の公開大会案内：https://hiroshima.hhbf1950.or.jp/大会関連/硬式部各種大会

## データと判定単位

`data/competitions/2026/hiroshima_primary_loser_forwarding_observations_2026.csv`（121行）：
- `observed_transition_id`・学校/合同チーム表示・一次予選敗戦ID・次の敗者復活ID・回戦・日付。
- 既存Stage14/15ほかの出典で照合できる場合は前後のブロック表示。
- `source_provenance=two_secondary_dated_match_results_not_official_draw`、`annual_loser_selector_verified=no`、`runtime_forwarding_authorized=no`を固定。

`data/competitions/2026/hiroshima_annual_route_evidence_requirements_2026.csv`（87行）：
- 一位校決定の一次予選38件：**学校の年度別ゾーン割付、一次予選の実組合せ**。
- 二位校決定35件：**どの一次予選回戦の敗者が二位校のどの組合せに進むか、二位校内部の実組合せ**。
- クロスゾーン県大会出場決定14件：**二位校イベントから進む候補選択、代表決定戦に負けた場合の再挑戦有無、クロスゲートの実組合せ**。
- これらは全て`draw_readiness=blocked_missing_official_transfer_and_pairing_evidence`、`live_fmt025_runtime_allowed=no`。見つかった公式PDFリンクだけでは解除不可。

`data/competitions/2026/hiroshima_annual_route_release_review_2026.csv`（8行）：各地区の必要証拠・観測数・割当枠を監査。進出枠は**予選63＝一次38＋その他25、直接免除1を加え県大会64**を保護する。

## 証拠パケットの形式検査

`phase2_engine/hiroshima_route_evidence_review.py`（純粋試作）：
- ルートIDと対象年、必要証拠項目の重複禁止、提出証拠キーの有効性を確認。
- 参照資料の種類を`federation_bracket_draw`（高野連組合せ図）または`federation_published_regulations`（高野連公開大会規定）に限定。
- 2026結果ページ・SportsOnlineイベント名・未閲覧PDFリンク・別年度限定の資料では証拠要件を満たさない。
- 資料の参照、抜粋位置、対象年度、本文の点検済みという申告がそろえば**手動内容審査に回せる形式**となる。
- それでもソフトウェアは参照先の本文の正しさ・相互整合を自動的に証明できないため`source_content_independently_verified=False`、`actual_game_runtime_enabled=False`を常に維持。
- **公式の資料を目視確認し、実際の経路を構造化・検証すること**は別工程で実施する。

`phase2_engine/hiroshima_stage13e3g21.py`：Stage18観測287辺から121辺を再生成し、保存CSVをすべてのフィールドで照合。87ルート別証明要件、8地区の枠保全、年度独立性の詐称・試合生成の不正解除を検出。

テスト25件：史実121/103、出場資格63と免除1、87経路、公式抽選と異なる偽資料の拒否、2027年の抽選への2026年専用資料の使い回し拒否、資料の本文未確認の場合の解除拒否、形式が完成してもライブゲームを有効化しないことの確認。

## 次の候補：Stage 13E-3G-22

1. 公式PDFの閲覧環境を再調査し、少なくとも1地区の**一次の敗者→二位校→クロスゲート**の実線矢印を原本の図上で確認する。
2. 原本を読み取れない場合は別の高野連一次資料・大会要項の探索と、証拠パケットの受入用レビュー表を作成する。
3. 1地区の実抽選の学校IDをマッピングして、公式の試合進行図に矛盾しないルール・ゲート型入力を設計し、**2026固定のカードと、将来年度ランダムに抽選できる条件を分離**する。
4. その結果が確定するまでは既存FMT025の簡略実行を変えず、任意順位戦は`design_pending`を維持。
