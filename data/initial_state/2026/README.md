# 2026年度開始時の前提データ（実在）

新規ゲーム（2026年4月1日開始）の最初の春季大会で必要になる、ゲーム開始前の実際の結果。方針は `docs/design/game_definition.md` §8。

ゲーム内で生成した結果ではないので、ゲームの記録（試合結果・戦績）とは混ぜない。春季大会の予選免除・シード・推薦を決めるための入力としてだけ使う。

## `prior_results.csv`

| 列 | 内容 |
|---|---|
| `record_id` | `ISR` + 6桁 |
| `kind` | `senbatsu_entrant`（2026年選抜の出場校）／`autumn_prefectural`（2025年秋の県大会）／`autumn_regional`（2025年秋の地区大会） |
| `rule_id` | 既存の予選免除ルールに紐づく行のみ設定。今回追加の秋季上位校データは空欄（同じ結果を各種シード制度から参照できる） |
| `source_year` | 結果の年 |
| `source_competition_name` | 大会名 |
| `prefecture_code` | 学校の都道府県 |
| `school_id` | `data/master/schools.csv` の学校ID。照合できない場合は空欄とし `notes` に理由を書く |
| `published_team_name` | 出典に書かれた校名 |
| `achievement` | `participant`（出場）／`champion`（優勝）／`runner_up`（準優勝）／`best4`／`best8`／`best16`／`main_entry`（本大会出場）／`regional_entrant`（地区大会出場） |
| `source_id` | `data/master/sources.csv` の出典ID |
| `verified_at` | 確認日 |
| `notes` | 補足（校名の判断、21世紀枠など） |

## 2025年秋季県大会の確定上位（2026年春季シード用）

47都道府県の各8校（優勝1・準優勝1・ベスト4の残り2・ベスト8の残り4）を記録し、2026年春季のシード数が16以上の青森・新潟はベスト16の残り8校も記録した。合計392校（新規360件＋既存32件の順位細分化）。北海道は秋季全道大会、東京は秋季都大会が対象である。新規行の `rule_id` は空欄とし、既存の予選免除用 `rule_id` は既存機能維持のためそのまま残した。

- 今回の上位校に連合チームの構成校への分割を要する記録は見つからなかった。
