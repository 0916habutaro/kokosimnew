# 選手名の生成用データ

架空の選手の名前をつくるための材料。実在の記録ではないので `historical_data/` ではなくここに置く。実在の人物の名前を使う意図はなく、たまたま同姓同名がいても架空の選手として扱う。使い方は `game_core/player_names.py`、重みは `config/players/player_names_v1.json`。

## `surnames.csv`（苗字）

- 列：`prefecture_code`（`data/master/prefectures.csv` の都道府県コード）, `surname`（苗字）, `count`（件数）
- 出典：電話帳の掲載件数（`data/master/sources.csv` の SRC000390）。件数は掲載世帯などの数で人口そのものではないが、都道府県の中の苗字の多い少ないの重みとして使う
- 元のデータ（47都道府県、837,984行）から**件数3以上**の行だけを取り込んだ（413,867行。行数で49.4%、件数の合計で98.2%）。件数1・2の珍しい苗字は入っていない
- 並びは都道府県コード、件数の多い順
- 読み（ふりがな）はない。「〆」を含む珍しい苗字もそのまま入れている

## `given_names.json`（名前）

- 男子の名前9,999件（重複なし）の配列。件数（頻度）はない
- 先頭の53件（蓮〜琥太郎）は人気の名前。それ以降はおおむね文字順で人気順ではない。先頭の何件をどれだけ重くするかは config に置く
- 出典：名前ランキングのサイトや名前が書かれているページから ChatGPT で集めたもの（SRC000391）。サイトごとの内訳はない
- 読み（ふりがな）はない
