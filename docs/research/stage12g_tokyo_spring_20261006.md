## 4. 4月4日の扱い

4月4日は雨天により、大田スタジアム・府中市民球場・新日本物流スタジアム多摩の第一試合が継続試合となり、全球場の第二試合が中止となった。

ただし東京都高野連公式結果には4月4日に完了した試合も掲載されているため、Stage 12Gの「完了試合が1試合以上存在する日を試合日として採用」という運用に従い、4月4日はMAIN試合日に含める。

## 5. 構造上の不整合

今回の調査で、日程とは別に既存大会構造の修正候補が判明した。

現在の登録:
- `PBR000025 / CMP000094`: `no_branch`
- `BGP000042 / CMP000094 MAIN`: `all_registered_teams`
- `STG000094`: MAINのみ

2026公式資料:
- 3月に一次予選を実施
- 3月22日の一次予選終了後に本大会組み合わせを確定
- 4月1日から本大会を実施
- 本大会は111校110ゲーム

このため、現行の `no_branch / all_registered_teams` は実大会の「一次予選 → 本大会」と一致しない。

Stage 12Gは日程構造化工程であるため、本PRでは大会エンジン構造自体は変更せず、Stage 12G完了後の構造修正候補として記録する。
