# 学校の編集

ユーザーが年数を進める中で、実際の校名変更・設置者の変更や、学校の実状（強くなった・弱くなった）に合わせるための仕組み。決定は `game_definition.md` §5 の5。

## 保存

- 編集はセーブ（スロット）のフォルダの `school_edits.json` に置く。`data/master` は書き換えない
- 学校ごとに、情報の変更（変えた日＝ゲームの日付と、変えた項目）と、能力の補正（今の段階と変えた日の記録）を持つ
- セーブを読み込むとき・新しく始めるときに、遊んでいるセーブの編集をゲームに反映する（`LiveGameService`）

## 学校の情報

- 表示名（学校の詳細に出す名前）・短い名前（一覧や試合に出す名前）・設置者
- 名前は、その日に有効な名前を出す。変えた日より前の試合は当時の名前
- 設置者は、表示と21世紀枠の公立の判定に使う（`DataRepository.ownership_type`）

## 能力の補正

- 打撃・投手・守備・走力をそれぞれ ±段階（範囲と1段階の大きさは `config/school_edits/school_edits_v1.json`）
- 補正は選手の能力に足す（`game_core/school_edits.py`）。選手の能力は選手と学校から毎回計算するので、今の部員にも今後の新入生にも同じように効く
- 学校の強さは補正した選手から計算する（ADR-001・006 のまま）。編集したら、試合の部品が覚えている能力・強さを捨てて、次の試合から効かせる
