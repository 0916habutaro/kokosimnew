# Stage 43G-64：セーブスロット選択・保存年度の校名と選手名

作成日：2026-10-12

## 位置付け

Stage43G-63の読取専用Tk履歴ビューアを、保存済みの複数セーブから選んで開けるようにし、画面で学校IDだけでなく**指定年度に保存された学校名**を表示する。正式なゲームGUI、セーブ作成・編集、全国大会進行エンジンの実装は行わない。

## 設計

- `CareerHistorySlotSession` は明示した `saves_root` 配下の直接子ディレクトリから、少なくとも1つの試合履歴SQLiteが既存の候補だけを読み取り専用で列挙する。ディレクトリの再帰検索・セーブ作成・スロット名だけからのファイル探索はしない。
- セーブ切替は`CareerHistoryGuiBridge`の新インスタンスを初期化した後で実施。選択前の年度候補、学校／大会／試合／選手ID、画面戻り履歴を新しいセーブへ持ち越さない。
- パスの外部参照・不正なスロット識別子は拒否する。誤指定・利用不能なセーブ・未封印データでは画面を切替えず、現在の選択を保持する。
- `CareerSavedYearDisplayLabels.school(year, school_id)` は当該保存年度の`career_school_rosters`をSHA照合し、ロスターの`school_name`を表示に採用する。年度にロスターがない場合にのみ現在の`schools.csv`等を利用し、その校名は「当時の名前である証拠はない」ことを明示する。
- `CareerSavedYearDisplayLabels.player(year, school_id, player_id)` は指定年度の保存ロスターと固定選手IDを照合して表示。氏名や背番号だけを根拠に時代をまたいで選手を同定しない。
- `project_history_screen(..., labels=...)` は元の出典・安定ID・未検証／検証済みフラグを維持し、学校・試合・選手の日本語見出しと注記を補う。リンク自体は表示名ではなく保存ID。
- `CareerHistoryTkPilot` に任意のスロット選択Comboboxを追加。セーブを変更すると年度一覧へ戻る。従来の `--slot` 引数と単一セーブ動作は維持。

### 試験画面の起動例

```bash
python -m phase2_engine.career_history_tk_pilot \
  --saves-root out/saves --slot-id EXAMPLE \
  --school-id SCH000001 --data-root data

# 従来の単一スロット起動も可能
python -m phase2_engine.career_history_tk_pilot \
  --slot out/saves/EXAMPLE --school-id SCH000001
```

## テスト

- 既存Stage43G-31の合成・封印済み2026年旧A方式および年10000のv2架空試合から、直接子スロットA・Bを作る。Aは2形式、Bは旧A方式のみを持つ。
- スロットAで年10000を閲覧した後、Bを選択して年10000・試合リンクが持ち越されないことを確認する。Bの年2026記録は正しく閲覧できる。
- 不正な識別子、親パス参照、存在しないセーブ、通常のテキストフォルダ、symlinkを拒否・除外する。
- 保存年度の学校・選手表示名をロスターと照合する。使い捨てB内の学校名だけを架空の旧校名に変更してSHAを再計算し、A側の校名へ影響しないことを確認する。
- Xvfb上の本物のTk Comboboxによる切替、失敗時の状態維持、およびセーブSQLiteのSHA-256不変を検証する。
- Stage43G-62～63回帰、全Python unittest、関東E2Eをmainマージ条件とする。

## 注意と未完了

これは2つの個別セーブを閲覧する機能であり、2つのセーブの年度・戦績・選手を統合する機能ではない。年10000の合成記録は実際に8000年間進行した結果ではない。

全国3,000校超の長期進行、正式ゲームのセーブ管理・選手キャリアUI、年10000以降の全国大会実行は別工程。学校マスター改称の年別履歴を本格採用する場合も、固定学校IDと保存済み年度スナップショットを優先する。
