## 用語と記入規則

1. **成績シード**：主催者がシードと指定した学校（前大会順位・新人戦・地区予選の順位等を根拠にする場合がある）。
2. **予選免除**：予選を通らず本大会へ直接出場する権利。シードとは独立する。
3. **初戦回戦／BYE**：1回戦免除は対戦組み合わせ上の事実。シード指定と同一視しない。
4. **枠番号／抽選番号**：公式組み合わせ表のトーナメント上の位置と、抽選時のくじ番号を区別する。例のCSVの配置位置・番号欄は原図未照合なら空欄。
5. **空欄 ≠ 0校、空欄 ≠ なし。** 確認できない数値は空欄。否定（「シードなし」など）も公式根拠なしには書かない。証拠の弱い推測は実値として記載しない。
6. 「本大会参加校数」は校数、チーム数（連合チームを含む）を区別して明記。3位決定戦の開催と地区大会への3位進出枠を混ぜない。
7. 未確定事項は必ず「未確定事項」に残す。2025年秋の大会成績を参照する2026年春のシードは、2025年制度に置き換えたという意味ではない。
8. `school_id` は学校マスターとのID照合をまだ行っていないため空欄。学校名は資料の掲載表記を保持。

### 継続する未確定事項

**本大会シード数未確定74/94行**。うち多くはシード有無自体を確定できていない。シード校数を確認済みのこの段階の16行についても、各県の正式な選定資格・順位の決め方、同地区回避、BYEの割当て、途中再抽選条文などの未解決が残る。**「公式原図で1回戦免除が観察された」だけでは再抽選なし／シードあり／シードなしを断定しない**。全県の抽選細則を確認するまではゲームの本番規則へ自動取り込みしない。

### 春季北信越：開催県4校と他4県優勝校が2022～2026年すべて交差

### 引き継ぎJSONの読み方

- `rules[ ].season`、`region`：大会識別子。秋10＋春9。**春北海道は `alias_prefectural_only`**、秋北海道・秋東京は `shared_prefectural_and_regional` として大会を二重生成しない。実際の `competition_id` との紐づけは `data/competitions/competitions.csv` を参照して実装時に行う。
- `host_2026`：2026年の開催県。実装では**県の表示名ではなく学校マスターに対応する都道府県コード**へ照合する。過年度開催県は `regional_host_history_2021_2022.csv`、`regional_host_history_2023_2026.csv` が別に保持している。未来の開催県確定アルゴリズムは**未決定**。

- `participants_2026`：2026年の出場チーム数。`draw.opening_round_matches`／`first_round_byes`：開幕回戦の試合数とその回戦を免除されるチーム数。確認式は**`participants_2026 = 2 × opening_round_matches + first_round_byes`**。

- `draw.placement_constraints`：`id`・`detail`・`observed_years`・`evidence_level` に分解している。原図で反復した配置であっても、明文規則が取れていなければ`observed_repeated`。特定年の反例は`observed_counterexample`、観測上の非発生は`observed_not_mandatory`と区別し、**実例だけで今後の厳密な強制規則を宣言しない**。
- `historical_overrides`：2021春九州19校・2021春東北中止・2021秋九州開催地変更・2026秋近畿の方式変更を別のレコードとして持つ。新規開始2026のゲーム本体へ、2021の特例を誤って適用しない。

### 抽選時の処理順序案

1. 当該大会が都県・道大会と**同一実体か否か**を確認し、必要な大会だけ生成する。大会キーは年度・季節・地区・既存 `competition_id` を整合させる。
2. **開催県の入力を確定**する。2026年は既知値。以後の開催県はゲームの年度計画などで別途決め、決まっていないときに史実として外挿しない。春東北の「次期開催県」も参加枠を割り当てる時点で確定が必要。
3. `entry` で県別通常代表枠を計算し、代表校（県大会順位）を取得する。秋近畿の3位校プレーオフは**勝敗が決まってから**出場校を追加する。春九州・春北海道は推薦の資格を別途解決する。
4. **出場校の学校IDを重複除去・検証**。学校の出身県・県順位・推薦資格・予選勝者の由来を失わず保持し、重複時に「1つの学校を2枠」入れない。推薦資格の重複で空いた通常枠の繰り上げ規則は未確認なら勝手に仮定せず、ゲーム仕様としての判断が必要。
5. 各地区ごとに**BYE対象と区画の県別分散を先に確定**し、次いで「県1位対他県2位」「同府県初戦回避」等の初戦条件を満たす学校を割り当てる。秋近畿の同府県準々決勝対決などの**観測済み反例**を拒否条件にしない。抽選できない場合は条件違反を無視するのではなく、理由を記録する。
6. 乱数の名前空間を年度・大会・シードに分け、セーブ再開・学校一覧の並びによって抽選結果が変わらない形にする。後続に未実装の再抽選がある場合、実際の大会に確認できていないルールを自動追加しない。
