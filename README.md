# 甲子園の通算記録の入力データ（参照用・マージしない）

ChatGPT で全国47都道府県分を集めた、学校ごとの甲子園の通算記録（夏は2025年、春は2026年まで）と、学校マスターとの照合の候補。
`historical_data/koshien_records.csv` に入れる元データとして使う。**このブランチは main にマージしない。** 取り込み終わったら削除する。

- 主に使うのは `input/甲子園全国47都道府県_2114春夏記録_ID候補付き_20261023.csv`（1校×夏春。`appearances=0` の行は入れない）
- 四国4県（36〜39）は年ごとの記録から数え直した値が main 側にあり、この表と99件すべて一致した。取り込みは四国以外の43都道府県
- 学校IDは候補（`game_school_id_candidate`）。`school_match_status` が「名称一致・校名候補」以外の約200件と、継承・統合の判断が要る学校は1校ずつ確認してから入れる
- 取り込みの手順は main の `historical_data/README.md` と引き継ぎメモを参照
