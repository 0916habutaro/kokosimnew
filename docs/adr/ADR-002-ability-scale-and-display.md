# ADR-002 通常能力は内部1〜100、表示は派生表現とする

- Status: Accepted
- Date: 2026-10-07

## Context

試合計算では細かな差を扱いたい一方、GUIではS〜G等の簡潔な表示も必要。

## Decision

通常能力は内部整数1〜100を正本とする。

GUIは必要に応じてS〜Gへ変換する。

球速は例外としてkm/h実値を持つ。

position_aptitudeは位置ごとの1〜100。

## Consequences

- 67と69の差を内部計算に利用できる。
- 表示方式を変えても内部データを変更しない。
- S〜G境界は設定JSONで変更可能。
