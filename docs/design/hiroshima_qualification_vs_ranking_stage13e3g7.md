# Stage 13E-3G-7：広島県大会資格と順位イベントの分離契約

## 資格決定経路の読み方

広島の2026年春秋は、地域毎に「1位校」「2位校」のサブ大会が存在し、一部ゾーンの2位校同士で最後の県大会出場枠を争う。その**ルート名**は、すべての内部試合について代表資格が確定したかどうかを証明しない。

したがって「○位校」「順位決定戦」を見つけただけで`RankingOnlyEventRuntime`へ自動取り込みしてはならない。2026年の歴史データとして出典付きで保存し、**両校がその試合の前に県大会出場資格を取得していた**ことが対戦ごとに証明された場合にのみ、`result_effect=ranking_metadata_only`のイベントを許す。

## 年度データと監査

`hiroshima_district_qualification_routes.csv`（87行）：春43、秋44の地区予選サブ大会。日付は**サブ大会初日と終了日**であり、個別試合の開催日ではない。正式な対戦日付と混同せず、個別試合を生成しない。

`hiroshima_qualification_examples.csv`（9行）：具体的な学校、実試合日、スコア、代表権判定が確認できる事例。既存RR20260032～34の3件を同一の資格決定として保護する。

`audit_2026_hiroshima_qualification_routes`：①全地区・春秋8区分のサブ大会件数、②地区・ステージの参照、③開催期間、④順位経路の資格への影響、⑤秋の地区別32枠、⑥春の既存32枠、⑦学校別9件の結果整合を検証する。

## 完了と保留の区別

「地区サブ大会87経路の分類完了」は「その全試合を勝敗・出場資格確定前後に分けて検証済み」ではない。公式PDFの全試合を直接照合できない場合、確認済み範囲と未確認範囲を報告書に明示し、RS2026026を解決済みにしない。マスターの地区所属・県大会出場枠・MAIN資格は変更禁止。
