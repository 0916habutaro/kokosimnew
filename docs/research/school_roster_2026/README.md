# 2026年の高校野球部員数：学校特性別の参考調査

> **調査資料（未確定）**。ゲーム用の能力・部員数生成パラメータや学校マスターに直接適用しない。調査日：2026-11-07。

## 目的

部員数を固定20人から可変にするため、県の平均差よりも、**学校規模・甲子園／県大会の常連度・学校固有の募集力**を優先して、2026年度の新入部員数の変動を分析する。

## 現時点の知見

- 2026年度の部員数に学校規模代理値を結合できたのは**165校**（公立121校、私立44校）。**9校は未結合**。
- 私立校は2026年の全日制**学則定員÷3**、公立校は**全日制募集定員**を1学年相当の規模代理値として使用。実在籍数、男子数とは異なる。
- 2021〜2025年の春夏秋の県大会ベスト8回数を常連度指標に使用。**2026年の成績を2026年入部人数の説明に使用していない**。
- 同一校の過去4年間の入部人数を加えると、2026年の予測MAEは学校規模＋常連度モデルより改善（Poissonで約4.77人→約3.34人）。
- Poissonは点予測、負の二項は平均NLLにおいて相対的に良い結果。ただし分布の採用・係数は確定していない。
- 部員の定義（選手のみ・マネージャー込み）、県大会参加校名の同定、学校改編、私立校の規模指標の比較可能性には注意が必要。

## 利用時の注意

1. 収録範囲は千葉中心で、全国を無作為抽出した標本ではない。**全国3,746校にそのまま外挿しない**。
2. 募集力と入学時の**選手能力品質**は別概念。部員数だけを理由に能力を直接補正しない。
3. 学校間の分散と同一校の年度間の分散は区別する。現状の結果ではPoisson・負の二項の最終採用を決めない。
4. 一部の学校名・年度・資料の役割定義は暫定。確認できない人数を推定で埋めない。
5. 保存形式・大会登録・人数不足時の合同チームは本資料とは別の実装課題。
