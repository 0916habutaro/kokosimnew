## 2. ゲームでの扱い・確度区分（ユーザー決定）

CSVの追加列 `ゲームでの扱い` の区分は次の3種類。**ゲームの運用値**と**実際の大会に関する確定事実**を混同しない。

| 区分 | ゲームで使用する値 | 根拠・注意 |
|---|---|---|
| **確定の規則** | CSVの数値と選定・配置条件を使用 | 2026年の主催者一次資料等でシード指定と数が直接確認できるもの。**将来年度も同じ規則との保証ではない** |
| **暫定値をそのまま使う** | CSVの既存シード数値（**0を含む**）を変更せず使用 | 当年の報道・過年度実績・非公式照合等。正式条文や総数が不足するもの。ゲーム用の既定値として採用するユーザー判断 |
| **仮の決まり** | **本大会の出場校が32校以上なら8校、32校未満なら4校。前の大会の上位から選ぶ** | **シード数が空欄の全大会**。県32・地区15に同一ルールを適用する**ユーザー決定**であり、史実・主催者規則ではない |

「本大会の出場校数」はゲーム内の**当該本大会に実際に参加するチーム数**（連合は1チーム）。予選段階の参加数ではなく、開催県追加枠・推薦・免除を反映した後の本大会人数で判定する。
もとの参加校数欄が空欄の大会では、ゲーム実行時に決まる参加校数で判定し、資料上の値を推測で埋めない。「前の大会の上位」の具体的な同順位処理などはゲーム側で一貫して仮決定し、史実の規則と表示しない。
**数値欄は原資料のまま残し、仮シード数を正式シード校数欄へ書き込まない。**
`ゲームでの扱い` に記載された「仮の決まり：…」の全文がユーザー指定の採用ルール。区分「確定」「暫定」は2026年資料の証拠の強さを示す区別。
