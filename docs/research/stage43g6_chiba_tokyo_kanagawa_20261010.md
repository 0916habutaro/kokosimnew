# Stage 43G-6：千葉・東京の予選免除を2027年度共通セーブへ統合／神奈川センバツ推薦枠監査

作成日：2026-10-10。前工程：Stage43G-5 PR #146（main反映済み・マージ後CI成功）。  
適用区分：**ゲーム内2027年度の明示的なsandbox出場校・仮日程**。2027年度の公式日程・出場校や成績を認定するものではない。

## 1. 目的と2027年関東8都県の状態

Stage43G-5までに茨城・埼玉の前年秋免除方式と、栃木・群馬・山梨の直接MAIN方式を年度内共通セーブに接続した。一方、千葉・東京はStage43F-6/7で個別大会を動かすことは検証済みでも、**2027年度の同一スロットに複数大会を登録し、日付順試合・全試合A履歴・ロードまで実際に一続きで確認するテストがなかった**。

今回はこの経路を追加する。また、神奈川県 `CMP000095` に対する`ACR000008`（センバツ出場校が同年春県地区予選免除・MAIN直接参加）を前年秋の順位と誤認しない監査を追加する。

## 2. 千葉・東京の前年秋成績と予選免除

`phase2_engine/career_multi_preview_checkpoint.py`の年次入力で、次の条件を明示チェックする。Stage43Fで実装した`prepare_future_prior_autumn_bypass_preview`は既に共通セーブのデフォルトアダプタとして呼べるため、**大会エンジンそのものは再実装しない**。

- **千葉 `CMP000092`**：`entry_mode=prior_autumn_bypass_v1`、2026秋千葉の保存・封印済みゲーム内上位8校を使用。2027年度の地区別参加校は全8地区を明示指定し、上位8校が地区予選に混入しない。別大会の前年秋結果IDを任意のsource overrideとして渡すことは禁止。
- **東京 `CMP000094`**：`entry_mode=prior_autumn_bypass_v1`、`prior_source_competition_id`に実際に封印された2026年度ゲーム内の東京秋季本大会結果IDを**必須指定**。その64校を2027一次予選から外し、一次予選の47代表と合わせてMAIN111校を構成する。東京秋季大会の独立2026公式マスターが未登録であるため、2026史実の64校を推測・生成しない。
- どちらも全出場校の2027進級済み`CareerRosterArchive`を必須にし、シード順位は付けない。ゲーム日付は`game_projection_v1`を維持する。
- 年度内の2大会は同一`career_multi_previews/2027.json`に登録し、`historical_matches.sqlite3`内の2027年度レコードを共有する。前年度sealedの試合結果・本人IDは変更しない。
- 従来`entry_mode`無しのStage43G-2/3/4セーブ入力のSHA-256形式は維持し、改訂したschemaに自動変換しない。

## 3. 神奈川のセンバツ出場校推薦資格

新規モジュール：`phase2_engine/future_kanagawa_invitational_access.py`、`audit_kanagawa_spring_access(repo,year=2027)`。

公式ベースの2026方式 `ACR000008` には、センバツ大会`CMP000001`の**同年度**出場校のうち神奈川県内の学校を、春季神奈川県大会`CMP000095`の地区予選から免除し本戦へ登録するルールがある。`quota_mode=all_matches`であり、厳密な「毎年1校」ではない。センバツ本大会のゲーム内出場学校の正本がなく、試合の一部だけを拾って出場者全体を確定することも不適切。

今回の監査で返す状態：

- `status=requires_same_year_verified_invitational_participants`
- `source_year=2027`、`source_competition_id=CMP000001`
- `automatic_bypass_enabled=false`、`runtime_ready=false`
- `no_record_interpreted_as_zero_participants=false`：**結果の記録がないことを「センバツ出場校0校」とみなさない**
- `main_seed_school_ids=[]`：推薦出場資格とMAINシードを別にする。
- 2026構造のアクション・学校出身県・予選免除・資格適用年が変わったときは監査を拒否する。
- 千葉や東京の前年秋上位校アダプタに神奈川を無理に渡すことも、栃木などの直接MAIN方式として神奈川を起動することも認めない。

将来、`CMP000001`の**当該年度の完全な出場校名簿**をゲーム内正本として保存・検証できるようになって初めて推薦枠を解決し、県大会MAINの試合生成に接続する。

## 4. 新しいテスト

`tests/test_stage43g6_chiba_tokyo_multisave.py`で、新規8テストを実施。

1. 試験用の2026千葉秋8校・東京秋64校のMAINを最後まで再現した勝敗・大会順位を同一SQLiteに保存し、年度をsealed。2027ロスターは千葉56校・東京112校分を2026から進級させて保存。
2. 千葉の前年8校は地区予選免除＋地区代表40校と合流、東京の前年64校は一次予選免除＋47代表と合流の契約を確認。
3. 共通セーブの初回試合日`2027-03-14`（東京一次予選）から試合を進め、2027年度の同じ履歴SQLiteへ打者・投手成績を保存。複数日を横断して再起動後に試合・抽選・seed・結果の一致を確認。
4. 2026のsealed履歴がそのまま残ることを確認。
5. 東京秋ゲーム大会IDの欠損・空欄・千葉のID誤指定・存在しないID、千葉への他県秋ID上書きを拒否。
6. 共通年度セーブの競合した古いセッションが上書きできないことを検証。
7. 神奈川センバツ資格は同年度の選手確認・出場者正本が未確定であり、**0校を確定扱いせず**保留にすることを検証。
8. 2026年や不正な年をセンバツ推薦ルールの未来年度に使わない。
