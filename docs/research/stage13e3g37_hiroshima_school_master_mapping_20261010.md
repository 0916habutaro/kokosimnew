# Stage 13E-3G-37：広島秋季西部18校名と2026学校マスターIDの安全な照合

実装日：2026年10月10日

## 目的

Stage34～36で表示している学校は、Stage25の2026年秋季広島西部の二次試合結果に登場する「広島商」「山陽」などの**表記名**であり、正式な学校マスターIDとは別物。学校別戦績の閲覧から学校マスターの情報を表示する際に、表記が似ているだけの別校や他県の学校へリンクしないようにする。

今回は「自動的に18校すべてを解決した」とみなさず、**2026広島県の現役硬式加盟校マスターに存在し、根拠が一意に確認できた学校のみ**学校IDとprogram IDを提示する。未照合の名称は明示的に保留する。

## 入力データ・判定方式

- `data/competitions/2026/hiroshima_autumn_west_match_nodes_stage13e3g25.csv`：2026秋季広島西部の二次結果、25試合・18校。
- `data/master/schools.csv`：正式`school_id`、`prefecture_code`、`official_name`、`federation_name`を参照。**既存ファイルは変更しない**。
- `data/master/baseball_programs.csv`：2026、`hardball`、`membership_status=active`の学校との対応を確認。
- `data/competitions/2026/post_qualification_rank_school_aliases.csv`：先行Stage13E-3G-4で根拠確認済みの別名対応。今回対象のうち、**「山陽」→SCH001774、「広島城北」→SCH001777**の2件だけを先行根拠IDとして使用。
- `data/research/2026/hiroshima_autumn_west_school_master_review_stage13e3g37.csv`：実際の18表記名と2026年・広島県コード34・別名先行確認有無を記録。

照合順位：
1. 広島県コード34、2026現役硬式加盟、`federation_name`が観測名と**完全一致して唯一**なら対応学校IDを採用。
2. 既存の確認済み別名台帳に明示されたschool ID、マスターの現在の正式校名・県コード・硬式加盟をすべて満たすなら別名から採用。
3. 完全一致と確認済み別名が別学校を指す場合、同一県に同名校が複数存在する場合、2つの観測名が同じschool IDに衝突する場合は**曖昧として全件保留**。
4. 正式校名の曖昧な部分一致、旧校名の類推、校順・地理的な近さは採用しない。該当候補がない学校は`unresolved_no_safe_unique_2026_master_link`とし、マスターIDを空欄にする。

名前の検索に正式校名を併用するのは、**当該学校が現在のプレビューで表示可能で、かつマスターIDがすでに一意検証済みの場合のみ**。待機中の試合の未知校、架空4校のIDを正式学校マスターへ接続しない。

## GUIへの接続

`phase2_engine/hiroshima_stage13e3g35_preview_gui_model.py` に、学校マスター参照を追加。史実シナリオのみ、学校マスターの一意照合を資料読み込み時に実施してキャッシュする。校別戦績テーブルに**「正式学校ID」列**を追加し、未確認は「未照合」、架空4校は「架空（対象外）」と表示。

`phase2_engine/hiroshima_stage13e3g35_preview_gui.py` の学校別戦績タブに「選択校の正式学校情報（照合済みのみ）」を追加する。選択された学校がプレビューで表示され、正式マスターIDも一意に照合できた場合に限り、**読み取り専用の学校情報ダイアログ**で観測名・正式校名・学校ID・2026硬式program ID・県コード・照合方式を表示する。未照合の場合は学校IDを類推せず、明示的な警告を表示する。

現段階では正式ゲーム用の学校詳細画面やBrowseRepositoryのSQLite更新とは接続しない。将来、正式な学校詳細へのリンクを張る際の参照キーとして使えるようにする試作である。

## 回帰テスト・監査

`phase2_engine/hiroshima_stage13e3g37_school_master.py` の `audit_2026_hiroshima_stage13e3g37()` は、18校、25試合、年度・県、2件の先行別名ID、正式マスターと2026硬式programの一意性、未解決の一覧を検査する。返却レポートの`links`は検証に成功したIDのみを収録し、未解決一覧は別に出力する。

`tests/test_stage13e3g37_hiroshima_school_master_mapping.py` では、同名複数校、他県同名校、硬式加盟年度や活動条件の不一致、別名台帳の改ざん、1校に2観測名を割り当てる衝突、観測校が表示される前の学校情報開示禁止、架空校の正式マスター誤照合を検証する。

## 未解決と次工程

公式2026秋西の試合番号25件・敗者移動矢印32件、2026春秋8地区の敗者経路48件は引き続き未確認。本番FMT025、任意順位戦、正式GUI、SQLiteへの書き込みは解禁しない。Stage38では、未照合校の根拠確認・正式学校詳細へのsafe link設計と、Windows実機GUIの手動受入確認を進める。
