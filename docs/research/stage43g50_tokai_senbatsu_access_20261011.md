# Stage 43G-50：愛知・三重の選抜出場校による春季地区予選免除の保存証跡

作成日：2026-10-11

## 工程と既存進捗
- Stage43G-48：静岡 `CMP000111` のFMT025予選→県本大会から東海2枠を認証済み。
- Stage43G-49：岐阜 `CMP000109` の前年秋封印済みゲーム記録・上位4校予選免除→県本大会から東海2枠を認証済み。
- 今回：愛知 `CMP000113`（`ACR000012`）・三重 `CMP000115`（`ACR000013`）は、**同年度センバツ `CMP000001` 参加校の地区予選免除**。前年秋の順位で代用しない。現行の架空2027年度セーブにあるセンバツ32校・31試合の完成結果を保存済みA方式SQLite記録と照合し、免除対象校だけを証明する。

## 実装
`career_tokai_senbatsu_access_gate.py` を追加し、
1. 全国センバツがMAIN単独方式、32実在校ID・全31試合のゲーム内トーナメントで完了していることを要求。
2. 同2027年度のSQLite `historical_matches` 全31行のID・対戦・勝敗・得点源・イニング別得点・打撃・投手成績・個別SHA・実施年を照合。追加／欠損試合、別年度・結果改ざんを拒否。
3. 県大会の2026基準マスターで愛知FMT010（5地区）、三重FMT016（3地区）とアクセスルールID・対象県・予選免除条件が一致することを要求。
4. センバツ32校のうち愛知・三重に所属する校だけをそれぞれ独立に抽出。学校のゼロ件は**全国32校の試合がすべて保存・検証できた場合だけ**確定可能。単に参加者レコードがない場合は「未確定」扱い。
5. `CareerTokaiSenbatsuAccessService.audit` は既存の共通年度セーブをロードし、当年センバツ完了と保存済み試合・現年度計画の一貫性を検証。権利を証明するが**県大会を自動で起動・追加しない**読み取り専用ゲート。
6. 自動シード位置の付与はしない。別途県大会のFMT010/016予選・MAIN接続と投影日程の調整が済むまでは `automatic_bypass_enabled=False` / `regional_runtime_ready=False` に固定。

## 日程上の未解決問題
2026基準の投影日では、
- センバツ：3月19～31日、完成済み全31試合の最終日が3月31日
- 愛知の春季地区予選：3月20日～4月3日、県MAIN開始4月11日
- 三重の春季地区予選：3月20日～4月2日、県MAIN開始4月11日

すなわちセンバツ全31試合を終えてから免除校を決定するだけでは、既に3月20日から進んだ地区予選を後から正しく編集できない。**本PRでは日付を勝手に改ざん・ゲームの過去日に試合をねじ込まない**。`schedule_conflict_requires_separate_activation_contract=True` で表示し、後続工程で予選開始時点の参加校マニフェスト確定と選抜大会同時進行・未確定校の暫定保留／遡及せずに再計算する手順を検討する。

## テスト
- 2026年封印済み架空ゲーム履歴、2027年進級ロスター、愛知・三重各2校入りセンバツ32校＋別大会を年度共有セーブに登録。
- センバツ31試合完了前は「不明」、完了後は2校ずつ免除資格の証跡を確定。A方式の全試合記録、SHA、日程の重複、前年ledger不変、手動セーブ不変を確認。
- 愛知・三重が0校の別の完全32校センバツなら「本当に0校」と認証。未実行・試合欠落・年度違い・SQLite改ざんは資格付与なし。
- 全体unittestと北海道推薦・関東・東北・四国・静岡・岐阜を回帰テスト。
