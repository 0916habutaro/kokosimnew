# Stage 43G-55：春季東海A方式履歴のTkinter試験GUI

作成日：2026-10-11

## 対象
Stage43G-54のread-only `CareerTokaiSeasonBrowseModel` と既存Stage43G-16 `CareerHistoryGuiPilot` を接続。対象は同年度センバツ・岐阜・静岡・愛知・三重・東海地区の計6大会。**2027年度の架空ゲーム内記録であり、公式大会の結果・出場校ではない**。

## 実装
- `career_tokai_season_gui_pilot.py`：Tkinterの独立ウィンドウ。Pythonの`-m`実行時は単体起動できる。既存の歴代記録GUIからは`春季東海ゲーム記録`ボタンにより、表示中の年度を引き継いで別`Toplevel`を開く。既存画面のナビゲーション履歴は変更しない。
- `TokaiSeasonScreenController`：画面/年度/大会/学校/試合/選手の保存済みIDを唯一の移動先とするheadless状態機械。大会一覧→大会別試合→試合詳細→学校戦績→選手記録→戻るを実現。ページ切替は30件単位とし、上限以上の空ページを勝手に追加しない。
- 全ページはStage43G-54のmodelに読み取りを依頼するだけであり、改ざん・未保存ID・年度不一致の例外発生時は画面状態を変更しない。UIでは警告ダイアログを表示する。
- 表では最小限の日付・試合スコア・学校/選手リンクを扱い、下部にread modelの保存済みA方式をJSONテキストで表示。ここでは未保存の打席イベント・投手勝敗・公式出場校情報を作成しない。
- 試験GUIには`公式大会結果ではありません`のラベルを常設。正式ゲームGUIへの画面統合、チーム編成・年度進行の操作は追加しない。

## 実行
```bash
python -m phase2_engine.career_tokai_season_gui_pilot --data-root data --slot out/saves/<slot_id> --year 2027
```
または既存の歴代閲覧試験GUIを起動し、保存済み年度を選んで`春季東海ゲーム記録`をクリックする。

## テスト・安全性
- headless：画面遷移/戻る/不正IDリンク・ページングによる状態破損防止、元SQLiteのSHA不変
- `xvfb-run`実Tk：Treeviewで大会→試合を選択、試合詳細を表示、戻る・年度・非公式記録ラベルを確認
- 既存歴代GUIのボタンで別ウィンドウを起動しても、既存の学校履歴routeを変更しない
- Stage43G-54のread model、Stage43G-16既存履歴GUI回帰を実行
- 対象は仮想保存データだけであり、SQLiteを明示的にread-onlyで参照。仮の日程・架空選手の試合結果を現実の公式資料と混同しない。
