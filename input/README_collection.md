## 出典と判定

試合結果の第一優先、通常の単一出典は日刊スポーツの朝日新聞社提供スコア。各地域のscore.htmlに掲載された日別リンクを取得し、勝敗が確定したスコア表を抽出した。出典URLは実際に取得した日別ページ。通常の試合について他サイトでの重複調査は実施していない。
年別参加数照合のみ日本高野連の公表値を使用：https://www.jhbf.or.jp/topics/detail/593 。抽選時の参加数であり、辞退・不戦・引分再試合等によって実施試合数と一致しないことがある。参加数−49は勝敗決定件数の照合用計算値であり、公表された実施試合数ではない。
各大会は日別リンク取得、重複キー、大会内チーム数−1、敗退重複、決勝1件、イニング別得点合計、表の終了回と明示終了回を検査した。日別リンク自体の掲載漏れがないことや主催者の全対戦表との独立照合は未確認。auditの「掲載範囲内整合」と主催者総数照合を混同しない。
「はい／いいえ」は確認できた値のみ。通常終了で9回以下はタイブレークなし。延長は掲載状態の「タイブレーク」明記を優先し、表記のない延長は空欄とした。年度ルールだけで空欄を埋めない。コールドは点差から推測せず掲載状態の明記を使用。終了回はイニング表の記録のある最終回（Xを含む）を読み取り、明示回数があれば照合した。
継続途中・試合開始前中止は試合結果から除外し、再開後の確定結果を終了日の日付で収録する。同じ試合の継続前後を二重計上しない。不戦で実施回や得点が確認できない場合、数値を創作しない。引分はall_gamesおよびdrawsで管理する。勝敗や状態を確定できない掲載はexceptionsで別管理する。
既存データと同じ年・都道府県・日付・対戦校組み合わせの結果は再追加しない。学校名の比較には全半角と空白の正規化だけを用い、改称・統合・別チームの同一視は行わない。既存試合に相違が出た場合は上書きせずconflictsに記録する。
大会名は既存データがある場合その表記を引き継ぐ。進捗表の京都府6年分「京大会」は「京都大会」に修正した。元ファイルはoriginalに保全。

## 集計

5回・7回コールドは終了回とコールド明記を併用し、6回・8回等はその他コールド。延長は終了10回以上。平均合計得点は両チーム得点の合計の平均。点差区分は互いに重複しない。割合の分母は収録試合数。必要項目が未確認の割合・平均は空欄とし、未確認を0扱いしない。確認済み件数は確認できた分のみを数える。

検査結果：既存351行の値・順序保全=True、統合重複=0、既存との相違=0、要確認掲載=0、終了回空欄=35、タイブレーク空欄=364。

GitHubへの変更は行っていない。

## 既存行の校名表記差

日付・回戦・両校得点・出典URL、および片側校名一致又は個別に確認した略称対応で照合した既存行の表記差は34件。name_variants.csvに旧表記と掲載表記を並べ、元行を維持したまま同一掲載の重複追加を防いだ。学校の歴史的同一性を一般化した名寄せではない。

original_audit.csvは元351行と現在の日別掲載の対応状況、source_audit.csvは日別内リンクの取りこぼし・日付・朝日新聞社表記・掲載ブロック数等の検査結果。
不戦勝の実施イニング等、該当しない項目も空欄となる。詳細未確認件数・空欄件数にはこの非該当を含む。不戦試合の通常の得点・9回・コールドなしを補っていない。

## 全結果と引分

all_games.csvはmatchesの12列を先頭に維持し、先攻校・後攻校・先攻得点・後攻得点・結果区分・掲載状態を追加した全結果。引分では勝者・敗者の4列を空欄とし、先攻・後攻の得点を収録する。draws.csvは引分のみ。matches.csvは従来互換の勝敗決定結果のみ。
summaryとcoverageの試合数はall_gamesの件数。引分再試合の元試合と再試合を別件で数える。summaryには勝敗決定件数・引分再試合件数・引分割合を追加した。得点・点差計算では引分の両校得点を使用し、点差0を勝敗の5区分に混ぜない。年別の参加チーム数−49との比較は引分を除いた勝敗決定件数で行う。
## 補助出典による1件補完

2023年7月2日兵庫大会1回戦、氷上7−2播磨南。日刊スポーツ当日スコアのデスクトップ・モバイル両版に掲載を検出できず、神戸新聞が県高野連データを基に掲載したスコア表で日付・回戦・得点・9回終了を確認して追加。9回の通常終了なのでコールド・タイブレークともなし。出典：https://www.kobe-np.co.jp/news/sports/koya/game/962/32528/ 。日刊スポーツ関連記事でも対戦・日付・得点は一致：https://www.nikkansports.com/baseball/highschool/news/202307020001369.html 。他の通常結果にこの補助サイトを重複使用していない。
2023年北北海道の標茶−別海は「没収試合」。掲載された0−9をそのまま保持し、イニング別の実得点と合計比較しない。実施イニングは空欄。
日別掲載範囲の整合に加え、終了回・コールド・タイブレークの3項目がすべて埋まる大会は201大会。残りは不戦等の非該当や未確認を含む。原351件の既存値のうち今回再確認できないものは変更せず、original_auditの「今回詳細再確認未了項目」に記録した。

## 完成範囲と残る空欄

completed_tournaments.csvに詳細3項目が全件埋まる201大会を列挙。unconfirmed_details.csvには通常結果で未確認の330件と、不戦・没収による空欄35件を理由別で収録。原351行のうち今回の再確認未了項目が残るものは5件あり、既存値をそのまま保全した。全294大会の全項目確認完了とは表示していない。
