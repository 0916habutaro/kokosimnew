# 画面の見た目の見本（参照用・マージしない）

段階2（正式な画面、ADR-044）の見た目の参考。ユーザーが WebView 版を選んだときの見本。
**このブランチは参照用。main にマージしない。** 正式な画面に取り込み終わったら削除する。

- `webview_sample/index.html`：見本の画面（大会のトーナメント表、学校一覧）。配色・トーナメント表の描き方・得点板の見た目の参考
- `shared/sample_data.json`：見本用データ（ゲームで2026年8月1日まで実際にシミュレーションした架空の結果）
- `screenshots/`：Windows の WebView2 で開いた画面（windows_*.png）と、Chromium で開いた画面

確認のしかた：このフォルダで `python -m http.server` を動かし、`http://localhost:8000/webview_sample/index.html` を開く（pywebview が無いときは `../shared/sample_data.json` を直接読む）。

見た目の要点
- 全体：濃い紺（#0e151d 系）の地に金（#f2b233）の差し色。数字は Bahnschrift
- トーナメント表：紙（#f5f1e6）の上に新聞風。左に校名、右へ勝ち上がり。勝者の線は赤（#d63a35）で太く、各線の上に得点。交点を押すと得点板、校名を押すと勝ち上がりを青で強調。Ctrl+ホイールで拡大縮小
- 得点板：深緑（#10301f）の板に、イニングの得点と合計（金）
- 学校一覧：見えている行だけ描く（3,746校でも軽い）。見出しで並べ替え、右に詳細
