# 2026年夏・49地方大会のシード指定／組み合わせ調査

更新基準：2026年11月8日。**史実照合用の参照資料**であり、ゲームの本番ルール・抽選器に自動反映される設定ではありません。

## この資料の目的

全国高等学校野球選手権の2026年地方大会について、次を混同せず保存します。

1. **成績シード**：主催者が順位・階級を指定した学校。春季ベスト8などと一致しない例もある。
2. **配置枠番号**：公開トーナメント表上のチーム位置。くじを引いた時の番号とは別。
3. **初戦回戦／BYE**：1回戦免除は成績シードと同義ではない。シード校でも1回戦から出場し得る。
4. **再抽選**：途中で組み合わせを作り直すイベント。勝者未確定枠を抽選する例もある。
5. **根拠の確度**：公式要項・公式原図、当年の抽選報道、試合記録、非公式仮説を分離する。

## 調査進捗の読み方

- 2026年の成績シード数が把握された47大会について、**学校別初戦照合の報告上は408／408校**。
- **このフォルダに学校別行が収録されているのは324校（31大会）**。初期の別資料で照合した84校分は、このファイルには収録されていません。**324行を408行と誤認しないこと。**
- これまでの調査の集計値では、公式原図の配置枠を直接確認済みとしたのは124校。東西東京の16校は文字抽出による暫定対応であり、この124校に算入しない。
- 北北海道・南北海道は、公式成績シードの採否と指定校数が未確定。**未確定 ≠ 0校**。ゲームでの暫定0校は史実の事実値と区別する。

## 史実データからゲーム仕様へ移す際の注意

- ゲームの夏の地方大会のシード・途中の抽選は、この資料から `data/competitions/`（`competition_seed_rules.csv` の `season_segment=summer`、`bracket_generation_policies.csv`）へ大会ごとに取り込んだ（2026-11-08。決まりと仮の決まりは `docs/design/game_definition.md` §8「夏の地方大会のシード」）。
- **本フォルダは閲覧・比較用**。変更前に`data/competitions/`、抽選ロジック、`docs/design/game_definition.md`との現行仕様差分を別途検証する。
- 史実の確度は「公式の条文」「当年の公式原図」「当年の結果・報道」「未確定の仮説」の順に判定し、確度の低い値を強制的に埋めない。
- トーナメント生成では、成績シード／ブロック固定／BYE／途中再抽選／地区接続を独立して扱う。
- 学校名表記の揺れ、公式枠番号とくじ番号の違い、各県の年度固有例外に注意する。
- 将来の資料追加時は途中版ファイルを増やさず、対象CSVと本READMEを更新する。
