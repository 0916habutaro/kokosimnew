# Stage 43G-35：封印済み新旧年度・試合詳細閲覧（試験版）

作成日：2026-10-11

## 起点
Stage43G-34／PR #175 の main 反映後に着手。既存画面は学校の試合一覧→対戦相手への移動はできるが、試合詳細を開く遷移がなかった。

## 今回の変更
- `CareerCrossEraBrowseModel.match_detail()` を追加。ユーザーが明示的に選んだ封印済み年度、学校ID、大会ID、試合IDを照合し、**旧ISO履歴原本または架空v2原本の片方だけ**から試合詳細を読む。
- 旧原本：保存レコードのSHA256、年・大会・試合主キー、学校・得点・勝者・ISO日付、回別得点合計とチーム得点を検証する。v2原本：架空暦と封印台帳を確認する既存の `year_matches` 経由で取得し、日付を `G{year}:MM-DD` のまま保持する。
- 保存済みの `inning_scores`、`team_stats`、`batter_stats`、`pitcher_stats` を項目別に渡す。旧方式で保存されていない項目は `None` のまま `missing_detail_fields` として明示し、仮のイニング・打撃成績・選手情報を生成しない。
- `CareerCrossEraNavigator` に `view=match` の専用routeを追加。対象レコードに対する検証を行ってから画面状態を切り替える。別年度に移動する場合は同じ試合IDを誤利用せず、その年度の学校ページへ戻す。
- Tk閲覧試験ウィンドウの各試合一覧に「試合詳細へ」を設ける。回別得点、チーム成績、打撃・投手記録を保存済み原本から表示し、詳細欄には全保存値・欠落項目・出典を表示。対戦校と学校一覧に戻るIDリンクも追加する。
- 旧年度と10000年度以降の統計を合算しない。学校・選手ラベルは正式IDと表示名を併記する。

## 安全性
- 原本SQLite、年度別ロスターSQLite、架空カレンダー、v2個人成績キャッシュは **読取専用**。表示のためのバックフィル、補完、DB作成、移行をしない。
- 年度が存在しない、封印されていない、改ざん、別の学校・大会・試合ID、異なる試合日付、得点不一致は拒否し、Tk画面の遷移前状態を維持する。
- 10000年度は人工fixtureを示すものであり、2026から10000まで進行したことを証明しない。
- 今回は閲覧試験GUIのみ。正式ゲームGUI、公式の実試合記録を示すものではない。

## テスト
