# Stage 43G-16：長期ゲーム履歴閲覧GUIの画面設計と独立試験版

作成日：2026-10-10。前工程 Stage43G-15 PR #156 main反映済み。
位置づけ：正式GUIの**情報契約・IDナビゲーションとTk試験画面**。完成版の正式GUIではない。

## 1. 現行GUIとの境界

既存 phase2_engine/browse_gui_stage13d3.py と browse_gui_model.py は、2026年向けの閲覧整形SQLite BrowseRepositoryを利用する。Stage43G-1〜15のゲーム内将来年度は異なるセーブ構造（historical_matches.sqlite3、career_rosters.sqlite3、派生集計）を使う。

二つのデータ形式を同一の試合・大会結果として自動で合体させない。特に広島2026研究用の二次史実プレビューはゲーム内結果ではない。本Stageはキャリア履歴**専用**の閲覧モデルと独立Tk試験画面を追加する。

## 2. 画面契約

新規 phase2_engine/career_history_browse_model.py：
CareerHistoryBrowseModel（読取専用）とCareerHistoryNavigator（履歴保持）。
HistoryRouteはscreen/year/school_id/player_id/competition_id/match_id/start_year/offset/metricを保持する。

| 画面 | 正本と表示内容 | 遷移 |
|---|---|---|
| 年度一覧 | career_yearsのactive/sealed、年度、保存試合件数 | 明示した年度へ |
| 学校詳細 | 正式学校ID、年度×大会勝敗・得失点、歴代所属選手のページ | 大会、選手、学校歴代 |
| 選手詳細 | 固定ID、在籍学年・背番号、A方式由来の年度別／通算打撃投球 | 学校へ |
| 大会記録 | 指定年度・大会で実際に保存された試合のページ一覧 | 試合へ |
| 試合詳細 | スコア・イニング別得点・打者／投手成績、出典 | 学校／選手 |
| 学校歴代記録 | 安打、本塁打、打点、盗塁、奪三振、投球アウト | 選手へ |

すべてにsource_kind=game_career_sandbox_not_officialを付す。表示名や見た目の行番号からIDを推測しない。試合はyear+competition_id+match_idを厳密に特定し、データを先に検証してから画面を切り替える。戻る際は同じ年度・学校の文脈へ戻り、存在しない対象なら現在の位置を維持する。

スコアだけが保存された旧試合のイニング得点や打撃・投球成績は0として埋めず、not_recordedと表示する。A方式の全打席イベントは未保存。大会試合一覧だけから優勝・準優勝・進出権は確定しない。

## 3. 試験用Tk画面

phase2_engine/career_history_gui_pilot.py を独立起動可能にした。年度選択、学校名／ID検索、学校別の年度戦績と歴代選手、選手通算成績、大会別試合、A方式試合詳細、学校歴代記録、ダブルクリックID遷移、戻る、学校／大会の前後ページ移動を実装。

コマンド：

    python -m phase2_engine.career_history_gui_pilot --data-root data --slot <セーブディレクトリ>

既存2026BrowseDBとは別画面。ゲームの試合進行、選手データ編集、セーブ変更、キャッシュ生成は行わない。Windows上の実画面での日本語文字表示、DPI、スクロール、キーボード入力、表示列幅の最終受け入れは未実施。

## 4. データ保護とパフォーマンス

- 画面描画ではStage43G-15の materialize 等のDB書き込み処理を呼ばない。既存のA方式正本から読み取り、派生キャッシュがない新規セーブでも閲覧可能。
- 学校戦績・歴代選手は標準1ページ30件、大会の試合は50件。モデルのoffset/limitでページ分割。
- Stage43G-13で追加した学校先頭索引を利用し、対象校・指定年範囲だけを順次検証する。全国3,000校×100年全試合を一度に表示しない。
- 試合はrecord_sha256を検証し、不一致なら画面への提供を拒否。選手成績はStage43G-14で実装した原本A方式の検証経路を使用。
- Stage43G-15のキャッシュは別途高速化のため利用できるが、**完全読取専用接続の契約と未生成・古いキャッシュの復旧方針**が確立するまでTk試験画面では使わない。

## 5. 自動テスト

tests/test_stage43g16_history_gui_navigation.py（新規11件、ヘッドレス）：
1. ゲーム内年度・封印状態・出典ラベル
2. 学校検索と複数年度戦績・歴代選手
3. 学校→選手→学校の戻り／年度保持
4. 大会→試合の複合ID、イニング・個人成績
5. 別年度・未知選手への誤遷移拒否
6. スコアしかない試合は記録欠損と表示
7. 保存済みA方式の学校歴代ランキング
8. 不正ID・ページ・試合SHA改変を拒否
9. 学校・選手・試合・歴代記録の閲覧で元履歴SQLite・選手SQLiteバイト列が変わらず、キャッシュも生成されない
10. Tk試験画面のPythonモジュールをウィンドウを作らずimportできること
11. 学校・大会のoffsetページングが正しく読み取れ、戻る操作でも画面文脈を保持すること

Python3.12の全ユニットテストと既存関東8都県E2Eの双方で回帰を確認する。Tkの実機表示はこのヘッドレステストだけでは保証しない。
