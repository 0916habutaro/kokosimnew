# Stage 43G-9：神奈川春季4地区FMT006＋センバツ同年推薦校のゲーム内2027年度統合

作成日：2026-10-10。前工程：Stage43G-8 PR #149（main反映済み）。
区分：2026年の制度・日程を投影した**2027ゲーム内sandbox**。2027年公式出場校・日程・推薦人数は推測しない。

## 1. 制度と根拠

神奈川県高野連の2026春季県大会は、川崎・横浜北地区23校、横浜南・横須賀地区23校、湘南・西湘地区18校、北相地区17校の計81校に、**センバツ出場校の推薦枠（2026年は横浜1校）**を合流した82校。2026大会の地区予選は各地区3～4校リーグ、3校リーグの2位校同士による補充代表決定戦を含むFMT006。

- 神奈川県高野連「2026春季県大会出場校一覧」 https://kanagawa-hbf.sakura.ne.jp/wp/wp-content/uploads/2026/03/%E4%BB%A4%E5%92%8C8%E5%B9%B4%E5%BA%A6%E7%A5%9E%E5%A5%88%E5%B7%9D%E7%9C%8C%E9%AB%98%E7%AD%89%E5%AD%A6%E6%A0%A1%E9%87%8E%E7%90%83%E6%98%A5%E5%AD%A3%E5%A4%A7%E4%BC%9A%E5%87%BA%E5%A0%B4%E6%A0%A1%E4%B8%80%E8%A6%A7.pdf
- Stage13Eの既存FMT006（POOL_RR→CROSS_PLAYOFF）・Stage43G-8の同年センバツ全32校参加名簿を使う。

## 2. 実装

### 2-1. 年度明示学校・4地区予選
新規 phase2_engine/future_kanagawa_fmt006_bridge.py。
- 対象CMP000095だけ。2027 sandboxの神奈川県内硬式学校だけが参加できる。
- Stage43G-8の「同年センバツ32校を検証済み」の資格正本を要求。神奈川県内の出場学校はすべて**地区予選から除外・本戦への直接進出**。センバツ不参加・名簿欠損から「推薦0校」を推測しない。校数0は全32校の完全名簿があって初めて許す。
- 2026方式の4地区（SGR000083～86）、出力枠23・23・18・17を検証。2027地区所属は**年次明示入力**。重複、県外、推奨免除校の地区混入、入力欠損、選手ロスター不一致を拒否。
- FMT006実エンジンで3/4校プール、リーグ試合、必要に応じる補充代表決定戦を実行。学年進級済み保存選手のAbilityMatchResolverにより打者・投手個人成績を伴う試合を実行。地区合計81代表校＋当年センバツ対象校をMAINへ統合。推薦校にはMAINシードを付与しない。
- 2026の地区予選3/20～28・MAIN 4/4～5/3を**月日のみ**ゲーム用2027仮日付へ投影。2027公式カレンダーとは扱わない。推薦校数によってMAIN参加数は変わり得る（固定82校にはしない）。

### 2-2. 同一2027年度SQLite／途中再開
新規 phase2_engine/career_kanagawa_spring_checkpoint.py。
- 既存Stage43G-8センバツ含む2027年度共通セーブを後から書き換えず、同じ2027歴史SQLite年度identityで別namespaceの県大会チェックポイントを持つ。保存先 career_kanagawa_spring_previews/2027_CMP000095.json。
- 校別の年次入力、センバツmanifest SHA、年度共通plan fingerprint、最初の抽選SHA、全試合checksumを保存。JSON先行→SQLite追記とし、中断／再起動後に全日付の試合を決定論的に再実行し、欠落していたSQLite記録だけ追記する。
- play_next_global_date()で同一年次共通セーブ上のセンバツ・他県と神奈川の**次の最も早いゲーム日付**を選び、対象大会の本物のA方式試合結果を同じSQLiteへ蓄積。年度封印済み2026台帳・既存manual/autosaveを変更しない。
- センバツ名簿がない・年度plan不一致・途中開始の日付逆行・既存セーブ競合・履歴改変・進行結果不一致は拒否。今回のチェックポイントは翌年度本編の正式シーズン自動管理ではない。
