# Stage 43G-40：東北・北信越・近畿・中国・九州の共通年度キャリアE2E

作成日：2026-10-11

## 目的と前段階
Stage43G-38では2026年全国47都道府県の硬式学校ID・162大会の構造監査を完了。Stage43G-39では東海・四国の2地域を試験用の2027年共通年度に接続し、能力モデルの試合結果・A方式の履歴保存、途中ロード、試合詳細閲覧を検証した。本工程は**同じ実装を新たな5地域で実行して、北海道・関東以外の7地区のサンドボックス実行を網羅**する。

各地区の参加校は2026実在校マスターから県別に均等に並べて抽出した**ゲーム試験用名簿**。当年地区代表の実際の学校名、代表校選出条件、主催地による枠数調整は実装しておらず、出場資格の証明にはならない。2027年ゲーム内予定も2026月日投影の仮日程である。

## 実施項目
1. 各学校に2026初期ロスターと2027進級ロスターを保存。2026年ゲーム内空封印履歴を原本とし、既存のゲーム・手動セーブを維持。
2. `CareerMultiPreviewCheckpointService` の既存明示 `non_kanto_regional_main_sandbox_v1` を使用し、5地区を同一2027年度のセーブに登録。
3. 最初の日付をプレイしてSQLite A方式・セーブを作成し、新プロセス相当の`load`で完全な予定・試合状態が再現されることを確認。
4. 5地区49試合すべてをプレイし、各地区優勝校、match_count、スコア、回別得点、打撃・投手個人成績の存在、学校IDの所属を検証。
5. 2027年度を**この5地区の試験分としてのみ封印**し、各地域の学校履歴→試合詳細を閲覧。閲覧前後のSQLiteのSHA一致と2026原本年度ledger不変を確認。
6. 地区外学校ID、学校数不足、未作成2027ロスターの混入は開始前に拒否。実際の出場校の資格を推測して補完しない。

## 残課題
- 北海道は春秋ともpre-MAIN構造を持ち、今回の単一MAIN地区E2Eとは扱いを分ける。
- 関東は2026開催県依存枠、前年秋免除、神奈川・千葉の特例を含む既存Stage43G-10 E2Eで別途検証中。
- 今回は**2027試験用5大会だけ**。全国の県予選から同年地区大会まで自動で進出する全国年度E2E、100年間継続する本番セーブ、正式ゲームGUIは未完了。
- 2026大会型の校数や試合日は将来年度にも固定であると主張しない。実際の2027年大会の学校別結果・日程も保存していない。
