# 選手名の元データ（参照用・マージしない）

段階4「選手名と出身地」の元データ。ユーザーから受け取ったもの。**main にマージしない。**

## `input/japan_surname.csv`（苗字）
- 列：`place`（都道府県）, `surname`（苗字）, `number`（件数）。47都道府県、837,984行
- 都道府県ごとに件数で重み付けして選ぶ（`number` は件数）。上位は妥当（沖縄：比嘉・金城・大城、鹿児島：中村・山下、東京：鈴木・佐藤）
- 件数1の苗字が約31万行あり、ファイルが大きい（15.8MB）。取り込むときは件数3以上（約41万行）などに絞ってよい（絞った割合を報告）
- 「〆」を含む苗字が65行ある（実在する珍しい苗字。そのままでよい）
- 読み（ふりがな）はない
- 出典：ユーザーに確認中

## `input/given_names.json`（名前）
- 男子の名前9,999件（重複なし、すべて漢字・かな）。元のファイル `input/names_original.json` は配列の [ ] がない形だったので、配列にしたもの
- **件数（頻度）はない。** 先頭の約53件（蓮・大和・翔・悠真・蒼・隼人…太一・拓海・翔太…琥太郎）は人気の名前の並び、それ以降はおおむね文字順で人気順ではない
- 重みの案：先頭の人気の名前を重く、残りは同じ重みにする。値は config に置く
- 読み（ふりがな）はない
- 出典：ユーザーに確認中
