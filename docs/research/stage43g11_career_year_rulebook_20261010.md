# Stage 43G-11：将来年度運用ルールの固定と本編への接続方針

作成日：2026-10-10。前段：Stage43G-10 PR #151 main反映済み（関東8都県17校のゲーム内E2E）。
本Stageは**段階的な管理層**であり、2027年以降の全国162大会の正式ゲーム運用・開催県自動決定・無限年数プレイの完了ではない。

## 背景と調査

既存の LiveSeasonGraphPlanner / year_transition.py は2026年度の本編向け。Stage43G-1〜10の2027年以降は CareerMultiPreviewCheckpointService、CareerKanagawaSpringCheckpointService、CareerRegionalMainCheckpointService に分かれた**明示参加校sandbox**である。いずれもゲーム用の仮日程・2026大会構造に基づく。

data/competitions/regional_feeder_rules.csv の RFR000007〜RFR000014 に2026年の構造が登録されている。**2027年以降に開催県が変われば出場枠も変わる可能性がある**ため、CMP000006 の17校・千葉3枠を将来に無条件で採用するべきではない。ゲーム用に「2026千葉開催構造を再利用する」と明示した場合のみ、既存の動作検証済み関東E2Eへ接続する。

## 新しい年度管理層

新規 phase2_engine/career_year_operation.py の CareerYearOperationService。

- register(slot_id, year, host_prefecture_code)：登録済み年度共通セーブを決定論的に復元し、前年封印台帳・年度共通プランSHAと2026出場枠ルールSHAを取得。career_year_rulebooks/{year}.json に **開催県というゲーム内仮定**、元ルールのハッシュ、出場枠の計算可能性、公式未確認フラグをチェックサム付き・原則変更不可で保存。
- **開催県を未指定**：出場枠を null にして保留。千葉開催を勝手に推定しない。
- **ゲーム内の開催県を千葉（12）と明示**：2026型の千葉3枠、ほか7都県2枠という17校のゲーム用仮定を使用可能にする。2027年の実際の開催県・枠を証明したことにはならない。
- **その他の都県を開催県と明示**：将来出場枠・仮日程の再構築が必要として、当該年度の地域大会開始を禁止。別県へ3枠を自動的に付け替える機能は未実装。
- load()：年度共通セーブ、封印済み前年記録、参照元CSVルールと年度チェックサムを毎回突き合わせる。開始後のhost・quota・参照元・seedの書き換えを拒否。
- audit()：登録済み大会ID、完了した大会ID、関東17校資格の現時点の認証状態、不足理由を出力。神奈川FMT006・千葉3位試合を経た実出場資格以外から進出確定しない。**登録していない全国大会は完了扱いしない。**
- start_regional()：ゲーム内千葉開催ルールの明示登録＋既存Stage43G-10の厳格な17校実結果検証を満たした場合だけ、関東大会チェックポイントを開始する管理側の入口。
- next_date()：既存年度共通試合、神奈川の独立チェックポイントを、保存済みの年度seedと試合記録に従って再開するラッパー。
- next_year_readiness()：前年分の一部大会が完成しても全国年度の完走とはみなさず、2028年への自動進級・翌年ロスター自動生成・イベント進出処理を明示的に拒否する。

## 履歴、将来の無制限年数要件

試合記録は従来どおり **A方式**（スコア、イニング別得点、打者・投手個人成績）をSQLiteに保持。打席単位イベントの永続保存は不要。既存の歴史を改変せず、年度・学校・大会ごとの索引とページングを使う設計を維持する。

「進められる年数は理想的には無制限」という最終要件は**未達**。現在の未来カレンダーとセーブ側には 2027 <= year <= 9999 のISO年月日・年次チェックがあり、本Stageでこの既存上限を解除しない。無制限化には内部ゲーム年IDと暦日表現の切り離し、100年規模の保存・読取・生徒進級・OB生涯履歴の負荷監査が必要。
