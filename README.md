# 初期の勢力図の入力データ（参照用・マージしない）

ChatGPT で集めた、全国大会の出場校の一覧（年ごと）。段階3a「初期の勢力図」で、学校の評判の「最近ほど重く」を計算するために使う。
**このブランチは main にマージしない。** 取り込み終わったら削除する。

- `input/national_entrants_1960_2026.csv`：1960〜2026年の選抜・選手権（夏）の出場校（5,101行、当時の校名と都道府県）、明治神宮大会は2022〜2025年。出典は日本高野連の出場校一覧ページ（`input/sources.csv`）
  - **2026年の選手権（夏）は使わない**（ゲーム開始の2026年4月より後の出来事）。2026年の選抜は使う
  - 学校IDは空欄。都道府県と校名で学校マスター・`historical_data/koshien_records.csv` と照合する。名前が変わった学校（例：明徳→明徳義塾）、同じ名前の別の学校に注意
- `input/autumn_regional_entrants_2025.csv`：2025年秋の地区大会の出場校（121行、二次資料）。直前の実力として使える
- 確認済み：2025年夏の49校・2026年選抜の32校は試合結果の記事と完全に一致。四国4県の主な学校の1960年以降の出場回数は、main の `koshien_appearances.csv`（年ごとに数え直したもの）と一致（明徳の旧校名分だけ別名で分かれている）。1960年代20大会は高野連の公式の校数と一致
- 使わないもの：2010〜2021年の春秋の地区大会の調査（決勝進出校など一部しかないため）
