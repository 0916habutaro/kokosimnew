## 達成したこと／達成していないこと

広島県高野連公式の「令和8年度秋季地区大会トーナメント表（広島西部）」について、公式高野連の公開ページのGoogle Drive「Image」プレビューを再確認した。

- 連盟公式ページ：https://hiroshima.hhbf1950.or.jp/大会関連/硬式部各種大会
- 当該年度・西部公式図：https://drive.google.com/file/d/1VxVW_r_L5MwnP3hkqZToGe3o5StK5NQ-/view?usp=sharing
- 図画像は表示可能。A/B/C/Dの一次上位・二位校側と、C/D2位による横断決定を確認する。
- 二次史実：https://www.reiwa-hb-sch-and-res-gatr-fod.com/hiroshima/2026autumn/west-area/
- 該当子大会：https://www.sportsonline.jp/reportv2/PublisherFull/Rally.aspx?ParentID=RX%5DSZ

**今回新しく原本の25個の試合番号を確定したわけではない。** 図の画像プレビューは最大表示状態でも細かな文字・矢印が十分に判別できず、元PDFバイトは引き続き取得できなかった。元PDF自体を持たない状態で、既存の試合結果から試合番号を割り当てる方法は採用しない。確実に判読可能となったときに採番・証拠位置・個別矢印を入力するための**57個の独立した確認項目**を整備した。

- `data/research/2026/hiroshima_autumn_west_official_number_review_queue_2026.csv`：25試合すべてについて学校・結果出典、公式図のゾーン見取り位置、公式番号／対戦の独立確認待ち、元PDF取得不可を分離する。
- `data/research/2026/hiroshima_autumn_west_official_arrow_review_queue_2026.csv`：32学校別接続について出場チーム名・移動前後の試合・一次敗戦等の理由、出発／到着の公式試合番号、公式矢印の位置、独立レビュアーと未確認状態を分離する。
- `phase2_engine/hiroshima_stage13e3g28.py`：
  1. Stage25の25＋32とStage27の8地区公式マクロ証拠を再監査し、台帳57件の漏れ・二重登録・進出先誤転送を検出。
  2. 試合番号・公式矢印を読んだと偽って空欄を埋める改変と、本体FMT025を有効にする改変を拒否。

  4. この関数が成功しても「公式資料からの独立確認済み」とは判定せず、`candidate_only=True`、`independently_official_verified=False`、`runtime_enabled=False` を返す。
- `tests/test_stage13e3g28_hiroshima_official_draw_review.py`：57件の完全性、一次敗者14件・C/D横断2件の優先指定、年次混同・偽公式番号・出典すり替え・擬似抽選ルール・live runtimeの誤解禁を拒否。

### 次の実務作業

連盟公式の2026秋西PDFの原本・高解像度表示を得られたら、以下の順に再点検する。

1. A～Dの各試合番号、対応するチーム名、回戦、番号の重複有無を25試合で独立転記。番号の図中位置（A区画上段など）と別途レビュアーを残す。
2. **14件の一次敗戦→二位校トーナメントへの移動**を公式図の矢印で確認。敗戦ラウンド別の転送先が完全か検査。
3. **C/Dの二位校勝者→追加代表決定戦の2入力**を公式図の番号・ゲートと照合。その後、残り16件の通常進行を確認。
4. 公式図に印刷されない移動関係がある場合、同年度高野連の別説明・規定資料を探す。**実結果の時系列だけで公式規定を補完しない**。
5. 公式全移動と独立審査完了後も、2027年度の抽選ルールへの一般化と本体FMT025接続は別承認とする。

今回のStageの達成は**57件を公式番号・個別矢印の独立確認キューとして保存し、将来転記の安全な突合機能を追加すること**。公式全番号・全矢印の解読完了を意味せず、順位戦`design_pending`は維持する。
